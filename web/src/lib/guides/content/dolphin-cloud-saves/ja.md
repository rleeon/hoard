Dolphin はマシン間でセーブを同期しません。ゲームキューブのメモリーカードもエミュレートされた Wii も、一台の PC のフォルダーにあります。Hoard はそれを自動で同期します。Dolphin を閉じるとゲームキューブと Wii のセーブをバックアップし、他の PC や Steam Deck に取り込み、すべてのバージョンを残すので、いつでも巻き戻せます。

## Dolphin のセーブの保存場所

すべては Dolphin のユーザーフォルダーにあります。いちばん早いのは、Dolphin の **File → Open User Folder** で開くことです。中には次のものがあります。

- `GC`：ゲームキューブのメモリーカード。
- `Wii`：エミュレートされた Wii の内部メモリー（セーブを含む）。
- `StateSaves`：ステート。

このフォルダーの場所：

- **Windows：** `Documents\Dolphin Emulator`。新しいインストールでは `%APPDATA%\Dolphin Emulator` を使うことがあり、ポータブル版では `Dolphin.exe` の横に `User` フォルダーがあります。
- **Linux：** `~/.local/share/dolphin-emu`。
- **Steam Deck**（Discover の Flatpak）：`~/.var/app/org.DolphinEmu.dolphin-emu/data/dolphin-emu`。
- **Mac：** `~/Library/Application Support/Dolphin`。

Hoard は `Documents`、Linux、Steam Deck のフォルダーを自動で見つけます。`%APPDATA%`、ポータブル版、Mac の場合は、`GC` と `Wii` のフォルダーを一度指定してください。

## ゲームキューブ：カードファイルか GCI フォルダーか

**Options → Configuration → GameCube** で、各メモリーカードスロットを次のどちらかにできます。

- **メモリーカードファイル**：`MemoryCardA.USA.raw` のような生イメージで、すべてのゲームのセーブが入っています。どのセーブでもファイル全体が書き換わります。
- **GCI フォルダー**：各セーブが独立した `.gci` ファイルになり、`GC/USA/Card A` のようなフォルダーに置かれます。新しくなるのは変わったセーブだけなので、バージョンは小さく、読みやすく保たれます。

同期には GCI フォルダーが向いています。どちらにしても、**すべてのマシンで同じ設定を使ってください**。片方がカードファイル、もう片方が GCI フォルダーだと、どちらも空のカードに見えます。種類を移し替えたいときは、Dolphin の **Tools → Memory Card Manager** で `.gci` ファイルをインポート、エクスポートできます。

カードは **リージョンごと**（USA、EUR、JAP）にも分かれています。同じゲームの PAL 版と NTSC 版は互いのセーブが見えないので、どこでも同じディスクイメージを使ってください。

## Wii：エミュレートされた本体のメモリー

Wii のセーブは `Wii` フォルダーの中、ディスク版のゲームなら `Wii/title/00010000/<ゲーム ID>/data` にあります。このフォルダーはエミュレートされた本体のメモリー全体で、セーブ、Mii、本体設定、インストールしたチャンネルが含まれます。Hoard はこれをひとつの項目としてバックアップするので、バージョンを復元すると本体のメモリーがその時点の状態に戻ります。確定する前に Hoard が何が変わるかを表示し、現在のファイルは先に保存されます。

Wii のセーブをひとつだけ手で移したい場合は、Dolphin でエクスポートできます。一覧のゲームを右クリックして **Export Wii Save** を選びます。

## 毎日の同期の流れ

デスクトップで遊んで Dolphin を閉じます。Hoard は Dolphin が終了してフォルダーが落ち着くのを待ってから、新しいバージョンをアップロードします。後で Steam Deck を手に取ると、オンラインになった時点で Hoard が新しいセーブを取り込みます。Deck で Dolphin を閉じれば、同じことが逆向きに起こります。二台が同時に電源オンである必要はありません。

## 知っておきたい落とし穴

- **ゲームだけでなく Dolphin を閉じる。** Hoard はエミュレーターが終了してからバックアップします。Deck では、スリープは終了に数えられません。
- **ステートは壊れやすい。** Dolphin のステートはバージョン間でよく壊れます。Hoard が同期するのは本来のセーブです。`StateSaves` も必要なら独立した項目として追加し、どこでも Dolphin のバージョンをそろえてください。
- **カスタムパス。** **Options → Configuration → Paths** で Wii NAND のルートや GCI フォルダーのパスを変えている場合は、Hoard にそのフォルダーを指定してください。

## 設定手順

1. 各マシンに Hoard をインストールし、同じアカウントでサインインします。
2. **ライブラリ** で、エミュレーターの一覧から Dolphin を追加します。
3. すべてのマシンで同じメモリーカード設定と同じリージョンを使います。
4. 遊んで、Dolphin を閉じ、もう一台で続けます。

家の中だけで完結させたいなら、PC か NAS で `hoard-server` を動かし、すべてのマシンをそこに向けてください。私たちのアカウントは不要、私たちへのテレメトリーもなく、私たちのサーバーを何も通りません。[Hoard をセルフホストする方法](/guides/self-host-hoard) を参照してください。他のエミュレーターについては [エミュレーターのセーブ](/guides/back-up-emulator-saves) を参照してください。

## よくある質問

### Dolphin にクラウドセーブはありますか？

いいえ。Dolphin はセーブをローカルフォルダーに置き、同期は利用者に任せています。Hoard はそれを自動で同期し、さらにバージョン履歴を残す方法のひとつです。

### PC と Steam Deck の間で Dolphin のセーブを同期できますか？

はい。同じアカウントで両方に Hoard をインストールしてください。Hoard は Windows、Linux、Steam Deck の Flatpak で Dolphin がセーブを置く場所を知っていて、マシン間で対応づけます。

### カードファイルと GCI フォルダー、どちらを使うべき？

同期には GCI フォルダーです。各セーブが独立したファイルなので、バージョンは小さく、どのゲームが変わったかがわかります。どちらを選んでも、すべてのマシンで同じものを使ってください。

### Wii のセーブも同期されますか？

はい。`Wii` フォルダーにはエミュレートされた本体のメモリーがセーブごと入っていて、Hoard はゲームキューブのカードと同じようにバックアップ、同期します。

### Hoard は Dolphin のステートも同期しますか？

既定ではしません。ステートは Dolphin のバージョン間で壊れるからです。必要なら `StateSaves` フォルダーを手動で追加してください。

### Android の Dolphin でも使えますか？

今のところ使えません。Hoard が動くのは Windows、macOS、Linux、Steam Deck です。
