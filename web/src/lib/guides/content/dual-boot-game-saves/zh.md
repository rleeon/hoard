在双系统 PC 上，同一款游戏会有两份独立的存档：一份在 Windows 的用户文件夹里，另一份在 Linux 的 Proton 前缀里。对于支持 Steam 云的游戏，Steam 云会把两者连起来；其余的从你第一次切换系统起就开始分道扬镳。Hoard 会自动让它们保持同步。用同一个账户在两个系统上安装它，不管你启动哪个系统，每款游戏的存档都会跟着你。

## 为什么一款游戏会有两份存档

硬盘是共享的，存档文件夹却不是：

- **在 Windows 上**，游戏会写入 `C:\Users\<你>` 下的 `Documents`、`Saved Games` 或某个 `AppData` 文件夹。
- **在 Linux 上**，同一款 Windows 游戏通过 Proton 运行，写入它自己的前缀：`~/.local/share/Steam/steamapps/compatdata/<AppID>/pfx/drive_c/users/steamuser/`，后面接同样的 Windows 路径。

同一份存档的两份副本，在两个永远不会同时运行的系统里。不管你最后在哪边玩，另一个系统都不知道。Hoard 会在两个位置查找，并按游戏把它们对应起来，于是 Windows 的存档和 Linux 的存档成为同一段历史的两个版本。

## Steam 云已经覆盖的部分

对于支持 Steam 云的 Steam 游戏，Steam 会自己在你的 Windows 安装和 Proton 安装之间同步存档。Hoard 在这里补上的是历史：Steam 只保留当前存档，一个坏存档会在两个系统上都替换掉好的。对于没有 Steam 云的游戏，以及 Steam 之外的一切，同步也由 Hoard 负责。

## 为什么不直接在 Windows 盘上共享一个文件夹？

这几乎是所有人的第一个想法：让 Linux 直接读写 Windows 分区上的存档，一劳永逸。通常会以三种方式出问题：

- **快速启动和休眠。** 开启快速启动时关机，Windows 会让分区处于半休眠状态，Linux 要么只读挂载，要么拒绝挂载。你的游戏写不了存档。
- **Proton 下的 NTFS。** 从 NTFS 盘运行 Proton 前缀或 Steam 库，是权限和文件名问题的常见来源。Linux 上的游戏在 Linux 文件系统上更稳定。
- **链接会被替换。** 把一个系统的存档文件夹软链接到另一个系统里，在某个游戏、更新或重装悄悄把链接换成真文件夹之前都能用。

让每个系统把存档放在游戏期望的位置，再在两者之间同步，三个问题都能避开。

## 设置步骤

1. **在 Windows 上** 安装 Hoard 并登录。
2. **在 Linux 上** 从 [下载页面](/download) 安装 Hoard，并用同一个账户登录。
3. **在 Linux 上把每款 Proton 游戏各启动一次**，让它的前缀生成。在此之前没有可以放存档的文件夹。
4. 在两个系统上查看 **库**：两边应该出现相同的游戏，Hoard 会按游戏把它们对应起来。

## 只有双系统才有的陷阱

两台独立的 PC 之间，存档会在服务器上等着，直到另一台来取。在双系统 PC 上，"另一台"就是重启后的同一台电脑，这会改变一个习惯。

Hoard 会在游戏关闭、文件夹安静下来之后上传存档。**如果你退出游戏后立刻重启，上传可能还没完成**，另一个系统启动时就没有你最新的进度。下次你再启动第一个系统时它会补上，但在那之前你可能已经在旧存档上玩了。

所以：退出游戏，给 Hoard 一点时间，在应用里确认存档已是最新，然后再重启。

## 原生 Linux 版本

有些游戏除了 Windows 版，还有原生 Linux 版。两者的存档格式不一定相同，有些甚至存在完全不同的位置。如果想在两个系统上用同一份存档，最稳妥的做法是在 Linux 上也用 Proton 运行 Windows 版：在 Steam 中打开 **属性 → 兼容性**，强制使用某个 Proton 版本。这样两个系统运行的是同一款游戏，写的是同样的文件。

## 设置与设备

两个系统的图形设置可能不同，所以 Hoard 会备份 `graphics.ini` 这类设置文件，但不会覆盖另一个系统上的设置。如果你仍想复制，还原时有专门的选项。

每个操作系统都算作一台独立的设备，所以一台双系统 PC 会占用免费方案三台设备中的两台。Pro 和自托管服务器没有设备数量限制。

希望存档留在家里？在 NAS 或另一台机器上运行 `hoard-server`，把两个系统都指向它。不需要我们的账户，没有发给我们的遥测，没有任何东西经过我们的服务器。参见 [如何自托管 Hoard](/guides/self-host-hoard)。

## 常见问题

### Steam 云会在 Windows 和 Linux 之间同步吗？

对于支持的游戏会：不管你在哪个系统上玩，Steam 都为每个账户保留一份云端副本。它没有历史，也不覆盖没有 Steam 云的游戏或 Steam 之外的任何东西。

### 能把存档放在共享的 NTFS 分区上吗？

不建议。快速启动可能让该分区在 Linux 中变成只读，而 Proton 在 NTFS 上有已知问题。让每个系统把存档放在自己的位置，再同步它们，更可靠。

### 为什么重启后我的存档没出现？

最可能的原因是重启时上传还没完成。重新启动第一个系统，让 Hoard 上传，在应用里确认后再切换。

### 双系统 PC 算一台设备吗？

不，算两台：每个操作系统都会注册为一台独立的设备。在免费方案中就是三台中的两台；Pro 和自托管服务器没有限制。

### 如果游戏有原生 Linux 版本怎么办？

它的存档可能和 Windows 版的不一致。要共享一份存档，就在 Linux 上也用 Proton 运行 Windows 版。
