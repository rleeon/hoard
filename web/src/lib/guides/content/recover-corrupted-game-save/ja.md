読み込めないセーブが完全に失われていることはめったにありません。たいていどこかに正常なコピーがあります。ゲーム自身が作ったバックアップ、Steam Cloud のコピー、Windows や OneDrive が残していた以前のバージョン、別の PC のセーブ。ただし順番が大事です。手順を誤ると、正常なコピーを壊れたもので上書きしてしまいます。まずここから始めてください。

## まず、手を止めてフォルダーをコピーする

1. **ゲームを終了し**、そのスロットで新しく始めないでください。これ以降のセーブは、古いコピーを押し出すおそれがあります。
2. **セーブフォルダーを丸ごと** デスクトップか USB メモリにコピーします。これで、この後に試すことはすべて元に戻せます。フォルダーの場所がわからなければ、[PC ゲームのセーブの保存場所](/guides/where-are-pc-game-saves-stored) を参照してください。
3. **そのフォルダーを同期するものをすべて一時停止します。** Steam Cloud（ゲームごとに **プロパティ → 一般**）、OneDrive、Syncthing。そうしないと、壊れたファイルが正常なコピーの残る唯一の場所へ届いてしまいます。

## 本当に壊れているか確かめる

壊れているように見えて、実はそうでないケースがあります。

- **ゲームがアップデートされた。** 古いセーブが読み込めない、あるいはパッチが必要になっていることがあります。ゲームのニュースやフォーラムを確認してください。
- **Mod が足りない。** 特に Bethesda のゲームは足りないプラグインを警告し、それを使っていたセーブを拒否することがあります。先に Mod を入れ直してください。
- **別のアカウントでログインしている。** Steam や Ubisoft のアカウント ID ごとにセーブを分けるゲームでは、別アカウントからは空のスロットに見えます。
- **ファイルがオンラインにしかない。** OneDrive で雲のアイコンがついたセーブは、空き容量を作るためにディスクから外されています。右クリックして **このデバイス上に常に保持する** を選んでください。

**0 KB** のセーブや、隣のファイルよりずっと小さいセーブは本当に壊れています。書き込みが途中で切れたのです。

## 正常なコピーがありそうな場所

順番に当たってください。最初のほうが早く、うまくいく可能性も高くなります。

### 1. ゲーム自身のバックアップ

予備のコピーを黙って残しているゲームは多くあります。セーブフォルダーで `.bak`、`_old`、`.backup` で終わるファイルや、追加のオートセーブスロットを探してください。よく知られた例：

- **Elden Ring** はセーブの横に `ER0000.sl2.bak` を書きます。
- **Stardew Valley** は各農場の `_old` コピーを残します。これはゲーム内の前日の状態です。
- **Terraria** はキャラクターとワールドの `.bak` ファイルを残します。
- **Minecraft Java** は各ワールドの中に `level.dat_old` を残します。

使うときは、壊れたファイルを脇へ移し（フォルダーはもうコピー済みです）、バックアップの名前を元のファイル名に変えます。

### 2. Steam Cloud

Steam Cloud が持っているのは **最新** のコピーだけで、履歴はありません。役に立つのは、最後のアップロードの後にセーブが壊れた場合だけです。たとえばゲームがクラッシュして、壊れたファイルが同期されなかったときです。Steam がゲームごとに持っているものは [store.steampowered.com/account/remotestorage](https://store.steampowered.com/account/remotestorage) で確認・ダウンロードでき、手で元の場所に戻せます。

### 3. Windows の以前のバージョン

セーブフォルダーを右クリックし、**プロパティ → 以前のバージョン** を開きます。そのドライブでファイル履歴かシステムの保護が有効だったなら、ここにフォルダーの古い状態が並び、開いて必要なファイルを取り出せます。一覧が空なら、どちらも有効ではありませんでした。

### 4. OneDrive のバージョン履歴

OneDrive が `ドキュメント` フォルダーをバックアップしているなら、多くのセーブが知らないうちにそこにあります。onedrive.com でセーブファイルを右クリックし、**バージョン履歴** を選ぶと以前のバージョンをダウンロードできます。OneDrive が保持するのは一定期間だけで、削除したファイルもしばらくはごみ箱に残ります。

### 5. ほかのマシン

最近ノート PC や Steam Deck で遊びましたか？そちらのコピーは問題が起きる前のものかもしれません。そのマシンが壊れたセーブを同期してしまう前にコピーしてください。

### 6. 壊れたのではなく削除された場合

まずごみ箱を確認してください。その後は、ファイル復元ツールで見つかることがあります。ただし、そのドライブへの書き込みを止めることが条件です。インストールやダウンロードのたびに可能性は下がります。

## 何も見つからないとき

人気のゲームのいくつかには、壊れたファイルを作り直せるコミュニティ製のセーブエディターや修復ツールがあります。ゲーム名と「save repair」で検索してみてください。それもなければ、正直なところ、意味があるのは問題が起きる前に作られたコピーだけです。

## セーブが壊れる理由

- **書き込み中のクラッシュや停電。** ゲームがセーブしている最中に止まった。
- **ディスクがいっぱい。** 書き込みを最後まで終えられず、途中で切れたファイルが残った。
- **同期ツールが書き込み途中でコピーした**、または二台の PC が同じセーブを編集し、片方のコピーが勝った。
- **Mod** がゲームの読めないものを書き込んだ。
- **ドライブの故障。** たいてい他のファイルにも症状が出ます。

## 二度と困らないために

上の復旧方法は、どれも運に頼っています。ゲームがたまたまバックアップを残していたか、Steam がまだ同期していなかったか。バージョン管理されたバックアップがあれば、運に頼る必要はなくなります。Hoard がやっているのはまさにそれです。遊び終えてフォルダーが落ち着いたところで、各セーブを自動でバックアップします。だからバックアップが書きかけのファイルになることはありません。すべてのバージョンが残ります。何かが壊れたら、そのゲームの **履歴** を開き、最後の正常なバージョンをワンクリックで復元します。現在のセーブは先に保存されるので、それすら元に戻せます。さらに Hoard はセーブを同期もしているので、ノート PC や Steam Deck にあるのが古く忘れられたコピーになることはありません。すべてのマシンが同じ履歴を共有します。

壊れた時点を見つけるコツ：二つのバージョンの間で急にサイズが落ちていたら、たいていセーブが途中で切れています。詳しくは [古いセーブデータを復元する方法](/guides/restore-a-game-save) を参照してください。

バックアップを家に置いておきたいなら、自分の PC か NAS で `hoard-server` を動かしてください。私たちのアカウントは不要、私たちへのテレメトリーもなく、私たちのサーバーを何も通りません。[Hoard をセルフホストする方法](/guides/self-host-hoard) を参照してください。

## よくある質問

### 壊れたセーブは修復できますか？

その場で直せることはまれです。コミュニティ製の修復ツールがあるゲームもありますが、ほとんどの場合、復旧とは古いコピーを見つけることです。ゲームのバックアップ、Steam Cloud、Windows や OneDrive、別の PC。

### Steam Cloud は古いバージョンのセーブを保持していますか？

いいえ。現在のファイルしか持っていません。壊れたセーブがすでにアップロードされていれば、Steam Cloud にあるのも壊れたものです。

### ゲームファイルの整合性を確認すれば、壊れたセーブは直りますか？

いいえ。整合性の確認はゲーム本体のファイルを Steam のものと照らし合わせるだけで、セーブは対象外です。ゲーム自体が壊れているときには役立ちますが、進行は戻りません。

### セーブが 0 KB なのはなぜ？

ゲームが書き込みを始めて、終えられなかったのです。クラッシュ、停電、ディスク不足のどれかです。横に `.bak` や `_old` のファイルがないか、別の場所に以前のバージョンがないか探してください。

### 再発を防ぐには？

ゲームが動いていないときに取る、バージョン管理されたバックアップです。Hoard はセッションのたびにそれを自動で行い、すべてのバージョンを残すので、どれにでも戻れます。
