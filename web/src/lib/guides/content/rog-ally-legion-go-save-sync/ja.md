ROG Ally、Legion Go、MSI Claw は Windows で動くので、ゲームから見ればただの PC がもう一台あるだけです。そしてそれこそが問題です。デスクトップと携帯機は、それぞれ自分のセーブを持っています。Steam Cloud はライブラリの一部を、Xbox のクラウドセーブは Game Pass をカバーしますが、それ以外は遊んだマシンに残ったままです。Hoard は携帯機とデスクトップの間でセーブを自動で同期します。片方で遊び終えれば、もう片方でゲームが待っていて、以前のバージョンもすべて残ります。

## すでについてくるもの

- **Steam Cloud 対応の Steam ゲーム** は自動で同期されます。
- **Game Pass と Xbox アプリのゲーム** は、両方のマシンで Xbox 版を遊ぶ限り Xbox のクラウドを使います。
- **Epic、GOG、Ubisoft、EA** は、一部のゲームについてそれぞれのランチャー内でクラウドセーブを提供しています。[Epic と GOG のクラウドセーブ](/guides/epic-gog-cloud-saves) を参照してください。

残るのは、開発者がクラウドを有効にしなかったゲーム、エミュレーター、手動でインストールしたゲーム、そしてデスクトップと携帯機で同じランチャーを使っていないゲームです。

## 設定手順

1. **携帯機で** Windows のデスクトップに切り替え、[ダウンロードページ](/download) を開いて Windows 版の Hoard をインストールします。
2. デスクトップと同じアカウントで **サインイン** するか、アプリを自分のサーバーに向けます。
3. **ライブラリ** を開き、Hoard が見つけたものを確認します。足りないもの、たとえばエミュレーターは、フォルダーを指定して追加します。
4. **デスクトップで** 同じアカウントで Hoard をインストールします。同じゲームは自動で対応づけられます。

同期エンジンは Windows と一緒に起動するバックグラウンドサービスなので、Armoury Crate、Legion Space、MSI Center M、Steam の Big Picture モードを使っている間も動き続けます。遊ぶために Hoard のウィンドウを開く必要はありません。

## 携帯機の落とし穴

### スリープは終了ではない

携帯機では、電源ボタンを押してゲームを開いたまましまうのがとても簡単です。Hoard はゲームが閉じてからしかバックアップしません。動いているゲームはセーブを書いている途中かもしれないからです。また、動いているゲームのセーブを差し替えることもありません。携帯機をスリープにしてデスクトップで遊ぶと、携帯機の進行はまだアップロードされていません。**マシンを替える前にゲームを終了してください。**

### microSD カードのゲーム

携帯機ではゲームをカードにインストールするのが普通ですが、セーブにはほとんど影響しません。たいていのゲームは、どこにインストールされていても内蔵ドライブのユーザーフォルダーにセーブするからです。例外はインストールフォルダーの横にセーブするゲームで、検出されない場合はフォルダーを手動で追加してください。

### 画面と設定

携帯機はデスクトップより解像度が低く、GPU も小さめです。Hoard は `graphics.ini` のような設定ファイルもセーブと一緒にバックアップしますが、もう一台の設定に上書きはしないので、それぞれが自分に合った設定を保ちます。それでもコピーしたい場合は、復元時にそのためのオプションがあります。

### 同じゲーム、違うストア

デスクトップ用に Steam で買ったゲームと、携帯機で Game Pass から遊ぶ同じゲームは別々のインストールで、Xbox 版は Xbox アプリにしか読めない形式でセーブします。ひとつのセーブを共有するには、両方で同じストアの版を遊んでください。

### Windows ではなく SteamOS や Bazzite なら？

その場合、携帯機は Linux マシンで、セーブは Steam Deck と同じく Proton プレフィックスの中にあります。[Steam Deck と PC の間でセーブを同期する方法](/guides/sync-saves-steam-deck-pc) を参照してください。

## 私たちのサーバーを使わずに

セーブを家に置いておきたいなら、PC か NAS で `hoard-server` を動かし、両方のマシンをそこに向けてください。私たちのアカウントは不要、私たちへのテレメトリーもなく、私たちのサーバーを何も通りません。[Hoard をセルフホストする方法](/guides/self-host-hoard) を参照してください。

## よくある質問

### ROG Ally にクラウドセーブはありますか？

各ランチャーが持っているものがあります。Steam Cloud、Xbox のクラウド、そして対応ゲームでの Epic、GOG、Ubisoft、EA のクラウドです。システム全体でセーブを同期する仕組みはありません。Hoard は、それらが取りこぼすゲームのための同期を加えます。

### Hoard は Armoury Crate や Legion Space で使えますか？

はい。Hoard の同期エンジンは Windows のバックグラウンドサービスで、ゲームを起動するランチャーとは独立しています。

### 携帯機はデバイスとして数えられますか？

はい。無料プランは三台までなので、デスクトップ、ノート PC、携帯機が収まります。Pro とセルフホストのサーバーには台数の制限がありません。

### Game Pass のセーブは？

Xbox のクラウドに任せてください。両方のマシンの Xbox アプリ間で同期してくれます。Hoard は独自のクラウドを持たないゲームをカバーします。

### 携帯機を Steam Deck とも同期できますか？

はい。Hoard は両方で動き、Windows と Deck の Proton プレフィックスの間で各ゲームを対応づけます。
