Steam Cloud 対応のゲームは、新しい PC でサインインすれば勝手に戻ってきます。それ以外はすべて、自分で運ぶべきフォルダーです。クラウドセーブのないゲーム、エミュレーター、Steam の外にあるもの。フォルダーを手でコピーすることもできますし、Hoard に古い PC でバックアップさせ、新しい PC でそれぞれ正しい場所に戻させることもできます。両方のやり方と、セーブを失う原因になる落とし穴を紹介します。

## 何かを消す前に

- **遊んでいるゲームを書き出す。** 何か月も触っていないゲームも含めて。忘れられるのはそういうゲームです。
- **クラウドセーブがあるゲームを確認する。** Steam ならストアページに書いてあり、**プロパティ → 一般** で有効かどうかわかります。Epic と GOG もゲームごとに表示されます。
- **残りはバックアップする。できればすべて。** クラウドセーブが持つのは最新のコピーひとつだけです。それが壊れていれば、どこでも壊れています。

## 手作業でやる

1. **ゲームごとのフォルダーを見つける。** ほとんどは `Documents\My Games`、`Saved Games`、または `AppData` のフォルダー（`Roaming`、`Local`、`LocalLow`）にあります。一覧は [PC ゲームのセーブの保存場所](/guides/where-are-pc-game-saves-stored) にあります。
2. **外付けドライブにコピーする。** フォルダー構造はそのままにします。Steam の `userdata` フォルダーも丸ごと持っていきましょう。小さく、Steam Cloud を有効にしないまま Steam 経由で保存するゲームもカバーします。
3. **新しい PC では、先にゲームをインストールする。** フォルダーを作る必要があるゲームなら、一度起動してメインメニューで終了します。新しく始めないでください。
4. **セーブを所定の場所にコピー** して起動します。古いドライブから何かを消す前に、進行が残っているか確かめてください。

これでうまくいきます。難点は一回きりのコピーだということです。すべてのフォルダーを覚えておく必要があり、古い PC で遊び続ければ、その日から二台はずれていきます。

## 落とし穴

- **アカウントに結びついたセーブ。** フォルダー名やセーブの中にアカウント ID を入れるゲームがあります。Elden Ring は SteamID ごとに、Ubisoft のゲームは Ubisoft ID ごとにセーブを分けます。両方の PC で同じアカウントなら問題ありません。別のアカウントだと、ゲームからは空のスロットに見えます。
- **OneDrive がドキュメントを移している。** 片方の PC だけが OneDrive で `ドキュメント` をバックアップしていると、「同じ」フォルダーが二か所に分かれます。`ドキュメント` を右クリックし、**プロパティ → 場所** で実際の場所を確認してください。詳しくは [OneDrive とゲームのセーブ](/guides/onedrive-game-saves) を参照してください。
- **ゲームのバージョン。** 新しいバージョンのセーブは、古いバージョンでは読み込めないことがあります。コピーの前に新しい PC のゲームをアップデートしてください。
- **Mod。** Mod 入りのセーブ（特に Bethesda のゲーム）は、同じ Mod がないと読み込めないことがあります。先に入れ直してください。
- **Windows から Steam Deck や Linux へ。** セーブはゲームの Proton プレフィックスの中に入りますが、プレフィックスはゲームを一度起動するまで存在しません。[Steam Deck と PC の間でセーブを同期する方法](/guides/sync-saves-steam-deck-pc) を参照してください。

## 自動でやる

Hoard にとって引っ越しは、毎日やっていることと同じです。片方のマシンでバックアップし、もう片方で復元する。

1. **古い PC で** Hoard をインストールしてサインインします。**ライブラリ** を開くと、Hoard が見つけたゲームのセーブが並びます。使っているのは Ludusavi と同じコミュニティのデータベースです。足りないものはフォルダーを指定して追加します。
2. **各ゲームの履歴にバージョンがあるか確認します。** **履歴** を見てください。古いドライブを消す前の安全網です。
3. **新しい PC で** Hoard をインストールし、同じアカウントでサインインして、ゲームをインストールします。Hoard はゲーム単位でバックアップと対応づけ、このマシンが期待するフォルダーに最新のバージョンを復元します。パスが違っていても（別のドライブ、別のユーザー名、Deck の Proton プレフィックス）問題ありません。
4. **新しく始める前に**、Hoard がセーブを戻し終えるのを待ってください。アプリに各ゲームの状態が表示されます。

コピーより安全な点が二つあります。`graphics.ini` のような設定ファイルはバックアップされますが、新しい PC の設定には上書きされません。新しいハードウェアは、それに合った設定で始まります（二台が似ていれば、復元時に設定も持ってこられます）。そして、何も取り返しがつかないことはありません。すべてのバージョンが履歴に残るので、間違った復元はひとつ前を復元すれば元に戻ります。

古い PC を使い続けるなら、新しい PC と同期し続けるだけです。もう使わないなら、デバイスから外してください。無料プランは三台までです。

## 私たちのサーバーを使わずに

これはすべて自分のサーバーでもできます。PC か NAS で `hoard-server` を動かし、両方のマシンをそこに向ければ、セーブは家から出ません。私たちのアカウントは不要、私たちへのテレメトリーもありません。[Hoard をセルフホストする方法](/guides/self-host-hoard) を参照してください。

## よくある質問

### Steam のセーブは自動で移りますか？

Steam Cloud 対応のゲームだけです。新しい PC でサインインしてゲームをインストールすれば、セーブがダウンロードされます。対応していないゲームは、フォルダーをコピーするか、代わりにやってくれるツールが必要です。

### ユーザーフォルダーを丸ごとコピーしてもいいですか？

ほとんどのセーブはそれで移りますが、何ギガバイトものキャッシュ、古いハードウェア向けの設定、新しい環境で問題を起こしかねないアプリのデータまで運ぶことになります。セーブフォルダーだけをコピーするほうがきれいです。

### Windows のユーザー名が違っても、セーブは動きますか？

はい、ほぼ必ず。セーブはユーザーフォルダーを基準に置かれているので、パス中の名前は関係ありません。Hoard はこれを自動で処理します。

### Windows から Steam Deck にセーブを移せますか？

はい。Deck で一度ゲームを起動して Proton プレフィックスを作り、その中にセーブを置きます。Hoard に任せることもできます。[Steam Deck のガイド](/guides/sync-saves-steam-deck-pc) を参照してください。

### 新しい PC の準備ができるまで、古い PC を残しておくべきですか？

手作業のコピーなら、すべてのゲームを確認するまで外付けドライブを残してください。Hoard なら、セーブはすでにサーバーにあるので、各ゲームの履歴にバージョンが表示された時点で古い PC を手放せます。
