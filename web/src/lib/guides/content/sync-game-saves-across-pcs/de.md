Wenn du auf mehr als einem Computer spielst — einem Desktop zu Hause und einem Laptop unterwegs — hält Hoard deine Spielstände synchron, damit du immer dort weitermachst, wo du aufgehört hast.

## So funktioniert die Synchronisierung

Hoard sichert jeden Spielstand in deiner Cloud und lädt die neueste Version auf deine anderen Geräte herunter. Wenn du an einem PC aufhörst, wartet der neueste Spielstand bereits am nächsten.

## Synchronisierung einrichten

1. Installiere **Hoard** auf jedem PC, an dem du spielst (Windows, macOS oder Linux).
2. Melde dich auf jedem Gerät mit demselben **Konto** an oder verbinde sie mit demselben selbst gehosteten Server.
3. Füge auf jedem PC dieselben Spiele zu deiner **Bibliothek** hinzu. Hoard ordnet sie pro Spiel zu, sodass ein auf einem Gerät gesicherter Spielstand auf den anderen erscheint.
4. Lass den **Automatikmodus** aktiviert. Hoard lädt nach dem Spielen hoch und vor dem Start die neueste Version herunter.

## Konflikte vermeiden

Hoard ist konfliktbewusst: Es vergleicht Änderungszeiten und behält eine lokale Kopie jedes ersetzten Spielstands, sodass eine Synchronisierung Fortschritt nie stillschweigend zerstört. Läuft ein Spiel noch oder wurde ein Spielstand in den letzten Minuten geändert, wartet Hoard.

## Tipp

Lass jedem Gerät einen Moment zum Synchronisieren, bevor du ein Spiel startest — das Dashboard zeigt den Live-Status, sodass du weißt, dass der neueste Spielstand bereitliegt.
