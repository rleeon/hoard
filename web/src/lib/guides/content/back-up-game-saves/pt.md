Perder um save significa perder horas de progresso. O Hoard faz backup dos seus saves de PC automaticamente e mantém um histórico completo de versões, para que você possa sempre voltar atrás.

## O que o Hoard guarda

O Hoard detecta as pastas de save dos jogos que você joga e as copia para a sua própria nuvem — o Hoard Cloud ou um servidor que você mesmo hospeda. Cada backup é versionado, então as cópias antigas nunca são sobrescritas.

## Configure os backups automáticos

1. **Baixe e instale o Hoard** para Windows, macOS ou Linux pela página de downloads.
2. Faça login, ou aponte o app para o seu servidor self-hosted.
3. Abra a **Biblioteca**. O Hoard procura os jogos instalados e lista os saves que encontra.
4. Adicione os jogos que quer proteger. O Hoard localiza cada pasta de save automaticamente; você pode adicionar um caminho à mão se um jogo não for detectado.
5. Deixe o **modo automático** ligado. O Hoard observa as pastas de save e faz o backup depois que você para de jogar.

A partir daí, cada sessão é capturada sem você fazer nada.

## Dica: confira o seu histórico

Abra a aba **Histórico** de um jogo para ver cada backup com data e tamanho. De lá você restaura qualquer versão anterior com um clique. Seus saves trafegam criptografados, são armazenados na UE e você pode exportá-los ou apagá-los quando quiser.
