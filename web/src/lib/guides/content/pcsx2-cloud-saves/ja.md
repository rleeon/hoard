PCSX2 は自分ではセーブを同期しません。PS2 の進行は一台のマシン上のメモリーカードファイルにあり、もう一台は何も知りません。Hoard はそれを自動で同期します。PCSX2 を閉じるとメモリーカードをバックアップし、他の PC や Steam Deck に取り込み、すべてのバージョンを残すので、ひとつの悪いセーブで冒険全体を失うことはありません。

## PCSX2 のセーブの保存場所

PCSX2 は本物の PS2 と同じく、メモリーカードに保存します。既定では `memcards` フォルダーに 8 MB の `Mcd001.ps2` と `Mcd002.ps2` の二枚があり、一枚のカードにそのカードで遊んだすべてのゲームのセーブが入ります。

- **Windows：** `Documents\PCSX2\memcards`。ポータブルモードでは、プログラムの横にフォルダーがあります。
- **Linux：** `~/.config/PCSX2/memcards`。
- **Steam Deck**（Discover の Flatpak）：`~/.var/app/net.pcsx2.PCSX2/config/PCSX2/memcards`。EmuDeck では、`~/Emulation/saves/pcsx2` のリンクがこれらのどれかを指しています。
- **Mac：** `~/Library/Application Support/PCSX2/memcards`。

PCSX2 の **Settings → Memory Cards** に、実際に使っているフォルダーと各スロットのカードが表示されます。Hoard は Windows、Linux、Steam Deck のフォルダーを自動で見つけます。Mac やポータブル版では、`memcards` フォルダーを一度指定してください。

## ファイル型カードとフォルダー型カード

PCSX2 は二種類のメモリーカードを作れます。同期するとき、この選択は見た目以上に重要です。

- **ファイル型カード**（`.ps2`）は、すべてのゲームのセーブが入った 8 MB のファイルひとつです。どのゲームでセーブしてもファイル全体が変わるので、新しいバージョンは毎回 8 MB まるごとになります。
- **フォルダー型カード**は、ファイルの代わりにフォルダーで、セーブごとにサブフォルダーがあります。あるゲームでセーブすると、そのゲームのファイルだけが変わるので、バージョンは小さく保たれ、履歴を見ればどのセーブが動いたかがわかります。

どちらも **Settings → Memory Cards** から作れます。どちらを選んでも、すべてのマシンで **同じ種類、同じカード名、同じスロット** を使ってください。デスクトップのファイル型カードと Deck のフォルダー型カードは別のカードで、どちらのマシンも相手のセーブは存在しないと考えます。

## 毎日の同期の流れ

デスクトップで遊んで PCSX2 を閉じます。Hoard は PCSX2 が終了し、カードが変化しなくなるのを待ってから、新しいバージョンをアップロードします。後で Steam Deck を手に取ります。オンラインになると Hoard が新しいカードを取り込み、PCSX2 を起動するとセーブがそこにあります。Deck で閉じれば、同じことが逆向きに起こります。

二台が同時に電源オンである必要はありません。カードはもう一台が取りに来るまでサーバーで待っています。

## 知っておきたい落とし穴

- **ゲームだけでなく PCSX2 を閉じる。** Hoard はエミュレーターが終了してからバックアップするので、書き込み途中のカードをコピーすることはありません。Deck では、スリープは終了に数えられません。
- **同じディスク、同じリージョン。** 同じゲームでも PAL 版と NTSC 版はシリアル番号が違う（たとえば SLES と SLUS）ので、互いのセーブが見えません。どこでも同じディスクイメージを使ってください。
- **ステートは別物。** ステート（`sstates` の `.p2s` ファイル）はエミュレーターのスナップショットで、別バージョンの PCSX2 では読み込めないことがよくあります。Hoard が同期するのはメモリーカードです。ステートも運びたい場合は `sstates` フォルダーを独立した項目として追加し、すべてのマシンで PCSX2 のバージョンをそろえてください。
- **バージョンはカード全体。** 以前のバージョンを復元すると、カード全体が、入っているすべてのゲームごと、その時点の状態に戻ります。確定する前に Hoard が何が変わるかを表示し、現在のカードは先に保存されるので、復元はいつでも元に戻せます。

## 設定手順

1. 各マシンに Hoard をインストールし、同じアカウントでサインインします。
2. **ライブラリ** で、エミュレーターの一覧から PCSX2 を追加します。
3. すべてのマシンでカードの種類、名前、スロットが同じか確認します。
4. 遊んで、PCSX2 を閉じ、もう一台で続けます。

家の中だけで完結させたいなら、PC か NAS で `hoard-server` を動かし、すべてのマシンをそこに向けてください。私たちのアカウントは不要、私たちへのテレメトリーもなく、私たちのサーバーを何も通りません。[Hoard をセルフホストする方法](/guides/self-host-hoard) を参照してください。他のエミュレーターについては [エミュレーターのセーブ](/guides/back-up-emulator-saves) を参照してください。

## よくある質問

### PCSX2 にクラウドセーブはありますか？

いいえ。PCSX2 はメモリーカードをローカルフォルダーに書き込み、同期は利用者に任せています。Hoard はそれを自動で行い、さらにバージョン履歴を残す方法のひとつです。

### PC と Steam Deck の間で PCSX2 のセーブを同期できますか？

はい。同じアカウントで両方に Hoard をインストールしてください。Hoard は Windows と Steam Deck の Flatpak で PCSX2 がカードを置く場所を知っていて、マシン間で対応づけます。

### ファイル型とフォルダー型、どちらを使うべき？

同期にはフォルダー型が向いています。変わったセーブだけがアップロードされ、履歴でどのゲームが動いたかがわかります。すべてのマシンで同じものを使う限り、どちらでも動きます。

### Hoard は PCSX2 のステートも同期しますか？

既定ではしません。ステートは PCSX2 のバージョン間で壊れるからです。必要なら `sstates` フォルダーを手動で追加し、どこでも PCSX2 のバージョンをそろえてください。

### 古いバージョンを復元すると、カード上のすべてのゲームが戻りますか？

はい。バージョンはカード全体です。Hoard は先に何が変わるかを表示し、置き換えるカードもバージョンとして残します。

### Android の PS2 エミュレーターでも使えますか？

今のところ使えません。Hoard が動くのは Windows、macOS、Linux、Steam Deck です。
