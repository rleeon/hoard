在很多 Windows 电脑上，OneDrive 会备份 `文档` 文件夹，往往是在设置系统时就打开了，没人注意到。在 `文档` 里存档的游戏，也就是几乎整个 `My Games`，都会跟着它进入 OneDrive。麻烦就从这里开始：存档写不进去，存档要先下载才能加载，还有带着你电脑名字、游戏永远不会读取的副本。下面说明原因和解决办法。

## 你的存档是怎么跑进 OneDrive 的

OneDrive 的文件夹备份会把 `文档`、`桌面` 和 `图片` 移到 `C:\Users\<你>\OneDrive\...`。游戏会向 Windows 询问 `文档` 在哪里，于是悄无声息地跟了过去。要确认，右键点击 `文档`，打开 **属性 → 位置**：如果路径里有 `OneDrive`，你的存档就在里面。

`AppData` 和 `Saved Games` 不在这项备份范围内，所以存档在那里的游戏不受影响。

## 会出什么问题

- **写入冲突。** OneDrive 会在文件变化的瞬间上传它。恰好在同一时刻写存档的游戏，可能会发现文件正被占用。
- **只在线上的存档。** OneDrive 可以把文件只留在云端来腾出空间（云朵图标）。这时游戏得先下载存档才能加载，离线时则什么也加载不了。
- **冲突副本。** 两台电脑用同一个账户开 OneDrive，两边都会同步同一个 `My Games`。在一边还没追上另一边时两边都玩，OneDrive 会把两个版本都留下，把其中一个改名加上电脑名。游戏会忽略那个文件。
- **空间。** 免费方案是 5 GB，有些游戏还会把模组、缓存或录像放进 `文档`。
- **不知道什么是一局游戏。** OneDrive 按文件同步，在游戏进行中就同步，并且为每个文件单独保留版本，而不是整个存档。

## 解决办法

### 快速：把存档留在设备上

右键点击 `文档\My Games`（或游戏自己的文件夹），选择 **始终保留在此设备上**。这能解决文件只在线上的问题，但不能阻止 OneDrive 在你游戏时同步。

### 彻底：停止备份文档文件夹

在 OneDrive 中打开 **设置 → 同步和备份 → 管理备份**，关闭 `文档`。Windows 会把 `文档` 指回本地文件夹，但已经备份过的文件会留在 OneDrive 文件夹里。关闭之前，先把它们设为 **始终保留在此设备上**，确保它们真的在硬盘上。然后在关闭游戏的情况下，把游戏文件夹移回本地的 `文档`，否则游戏会从头开始。

## 更好的分工

OneDrive 擅长处理文档。存档需要的是别的东西：在游戏关闭后才做的备份，以整个存档而不是单个文件为单位的版本，以及与其他电脑和 Steam Deck 的同步。

这正是 Hoard 做的事。不管 `文档` 在不在 OneDrive 里，它都能找到你的存档，因为它会向 Windows 询问这个文件夹真正的位置。它在每次游戏结束后自动备份，保留每个版本，并同步到你的其他机器。

只有一条规则：电脑之间的同步只交给一个工具。如果 OneDrive 在多台使用同一账户的游戏电脑上备份 `文档`，它其实已经在这些电脑之间同步那些存档了。在这些电脑上关闭 `文档` 的备份，把存档交给 Hoard。

完全不想用云？在你的 PC 或 NAS 上运行 `hoard-server`：不需要我们的账户，没有发给我们的遥测，没有任何东西经过我们的服务器。参见 [如何自托管 Hoard](/guides/self-host-hoard)。

## 常见问题

### 要让 OneDrive 备份我的游戏存档吗？

在单台电脑上作为备份，有总比没有好。用来在电脑之间同步存档则会产生冲突，因为它不知道游戏什么时候在运行。

### 我关闭了备份，存档不见了。它们在哪里？

还在 OneDrive 文件夹里：`C:\Users\<你>\OneDrive\Documents\My Games`。关闭游戏，把它们移回本地的 `文档`。

### 带着我电脑名字的存档文件是什么？

OneDrive 的冲突副本。两台电脑在同步之前修改了同一个文件，OneDrive 把两个都留下了。弄清楚哪个更新，给它改回原来的名字，把另一个放到一边。

### OneDrive 能帮我找回较早的存档吗？

有时可以。在 onedrive.com 上右键点击文件，选择 **版本历史记录**。它按文件处理，而且只在有限的时间内有效。参见 [如何恢复损坏的游戏存档](/guides/recover-corrupted-game-save)。

### 文档文件夹在 OneDrive 里，Hoard 还能用吗？

能。Hoard 读取 Windows 给出的 `文档` 位置，所以无论在哪里都能找到存档。
