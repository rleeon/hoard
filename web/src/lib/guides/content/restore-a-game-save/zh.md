游戏中的错误决定、损坏的文件，或失败的 Mod——有时你只需要回退。由于 Hoard 为每个存档保留完整的版本历史，恢复较早的版本只需几秒钟。

## 恢复之前的版本

1. 打开 **Hoard**，进入 **库** 中的游戏。
2. 打开它的 **历史** 标签。你会看到每个备份及其日期和大小。
3. 选择你想要的版本，点击 **恢复**。
4. Hoard 会把该快照写回游戏的存档文件夹。你当前的存档会先被备份，因此恢复本身也是可逆的。

## 在新电脑或重装后的电脑上恢复

1. 安装 Hoard，并用你的账户登录。
2. 把游戏添加到你的库中——Hoard 会找到对应的云端备份。
3. 恢复最新版本或任意较旧的版本，然后继续游戏。

## 提示

恢复操作绝不会造成破坏：被替换的存档会先作为新版本记录下来，因此你随时可以通过恢复上一条记录来撤销一次恢复。
