Hoard CLI

Hoard dal terminale

Un unico binario hoard — niente installer, niente finestra. Lo stesso motore di sincronizzazione dell'app desktop, ma headless. Perfetto per un server, un NAS o una Steam Deck.

Esegui questo nel terminale per installare:

Linux · macOS

/install.sh
curl -fsSL https://raw.githubusercontent.com/rleeon/hoard/main/web/static/install.sh | sh

Windows · PowerShell

/install.ps1
irm https://raw.githubusercontent.com/rleeon/hoard/main/web/static/install.ps1 | iex

Versione 1.1.6 · rilasciata il 2026-09-03

Cosa fa questo comando

  1. 1

    Rileva il tuo sistema operativo e l'architettura della CPU.

  2. 2

    Scarica la build giusta dall'ultima release di GitHub — il binario hoard (hoard.exe su Windows).

  3. 3

    Verifica il download con il suo checksum SHA-256 pubblicato.

  4. 4

    Lo installa in una cartella della tua home e lo aggiunge al tuo PATH — senza admin né sudo.

È uno script in testo semplice — apri il link install.sh / install.ps1 qui sopra per leggerlo prima di eseguirlo.

Cos'è Hoard CLI?

Cos'è

Un eseguibile autonomo che salva, ripristina e sincronizza le tue partite dalla riga di comando. Senza desktop né dipendenze.

Per chi è

Macchine senza schermo: server, un NAS o una Steam Deck in modalità gioco. Configurala una volta e lasciala girare in background.

Lo stesso motore

La CLI e l'app desktop condividono lo stesso identico core, quindi ogni funzione si comporta allo stesso modo.

I comandi che userai davvero

Una volta installato, è tutto qui il quotidiano. Alla maggior parte bastano i primi due.

  • hoard login Accedi a Hoard Cloud o al tuo server self-hosted.
  • hoard sync start Installa e avvia il servizio di sync in background — rileva i tuoi giochi e controlla i loro salvataggi, anche dopo il riavvio.
  • hoard sync Mostra lo stato del servizio e l'attività di sync recente.
  • hoard track <game> Traccia manualmente un gioco specifico se il rilevamento l'ha mancato.
  • hoard snapshots list <id> Elenca tutte le versioni salvate di un gioco.
  • hoard restore <id> Riporta un salvataggio a uno snapshot precedente.

Oppure scarica manualmente

Prendi il tarball per la tua piattaforma e metti il binario nel tuo PATH da solo.

Windows

  • hoard-1.1.6-windows-x86_64.tar.gz x64
  • hoard-1.1.6-windows-aarch64.tar.gz ARM64

macOS

  • hoard-1.1.6-macos-aarch64.tar.gz Apple Silicon

Linux

  • hoard-1.1.6-linux-x86_64.tar.gz x64
  • hoard-1.1.6-linux-aarch64.tar.gz ARM64 · RPi / ARM server

I tarball per Linux includono anche hoard-server e hoard-admin per l'auto-hosting.

Linux · macOS

tar -xzf hoard-*-*.tar.gz
mv hoard-*/hoard ~/.local/bin/
hoard login

Windows · PowerShell

tar -xzf hoard-*-windows-x86_64.tar.gz
# move hoard.exe onto your PATH, then:
.\hoard.exe login

Sostituisci versione e piattaforma in ogni nome file con quelli che hai scaricato.
