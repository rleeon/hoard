Steam Deck と PC の間でセーブを同期する方法

更新日 2026-10-09

Steam Cloud に対応した Steam のゲームなら、Deck と PC はすでにセーブを共有しています。助けが必要なのはそれ以外です。開発者が Steam Cloud を有効にしなかったゲーム、Heroic で起動する Epic や GOG のゲーム、エミュレーター、非 Steam ゲームとして追加したもの。Hoard はこれらすべてを自動で扱います。片方のマシンでゲームを終了するとセーブをバックアップし、もう片方のマシンがそれを取り込みます。何かあったときのために、以前のバージョンもすべて残ります。

Deck で Steam Cloud がすでにやっていること

ゲームが Steam Cloud に対応していれば、Steam は終了時にセーブをアップロードし、別のマシンで起動するときにダウンロードします。対応しているかはストアページで確認でき、ゲームごとに プロパティ → 一般 でオフにできます。

穴はいつも同じです。

  • 対応していないゲーム。 有効にするかは開発者がゲームごとに決めます。一度も有効にしていない PC ゲームはたくさんあります。
  • Steam の外にあるもの。 Heroic、Lutris、エミュレーター、手動でインストールしたゲーム。
  • 戻れない。 Steam が持つのは現在のセーブだけで、履歴はありません。壊れたセーブが同期されると、両方のマシンから正常なセーブが消えます。

詳しくは Steam Cloud の代わり のガイドを参照してください。

Deck のセーブの保存場所

Deck は Windows 用ゲームを Proton で動かすため、同じゲームでも PC とは保存場所が違います。

  • Windows 用ゲーム（Proton）： ~/.local/share/Steam/steamapps/compatdata/<AppID>/pfx/drive_c/users/steamuser/ の後に、いつもの Windows のパスが続きます。Documents、AppData/Roaming、AppData/Local、AppData/LocalLow、Saved Games のいずれかです。AppID はストアの URL にある数字です。
  • microSD カード上のゲーム： カードにも独自の steamapps/compatdata/<AppID> があり、中の構造は同じです。
  • ネイティブ Linux ゲーム： たいてい ~/.local/share/<ゲーム> か ~/.config/<ゲーム>。Unity 製のゲームは ~/.config/unity3d/<会社>/<ゲーム> を使います。
  • Heroic、Lutris、Bottles： それぞれゲームごとに Wine プレフィックスを持ち、Windows の構造は steamuser ではなく drive_c/users/<あなたのユーザー名>/ の下にあります。
  • エミュレーター： EmuDeck は ~/Emulation/saves/ にまとめます。エミュレーターのセーブ と RetroArch を参照してください。

PC では、同じゲームが C:\Users\<あなた>\... に書き込みます。ひとつのセーブにパスが二つ。手でフォルダーをコピーすると失敗するのはこのためです。Hoard はこれらすべての場所を探し、見つけたものをゲーム単位で対応づけます。こうして Deck のセーブと PC のセーブは、ひとつの履歴の二つのバージョンになります。

設定手順

  1. Deck でデスクトップモードに切り替えます：Steam ボタン → 電源 → デスクトップに切り替え。
  2. ブラウザーで ダウンロードページ を開き、Linux 用の Hoard Setup を入手します。ファイルマネージャーでファイルのプロパティを開き、プログラムとしての実行を許可してから起動します。
  3. PC と同じアカウントでサインインするか、アプリを自分のサーバーに向けます。
  4. ライブラリ を開き、Hoard が見つけたものを確認します。足りないものは、そのフォルダーを指定して追加します。Heroic のプレフィックス、エミュレーター、自分でインストールしたゲームなどです。
  5. 同じアカウントで PC にも Hoard をインストールします。同じゲームは自動で対応づけられます。
  6. ゲームモードに戻ります。もうデスクトップモードに戻る必要はありません。

Hoard Setup はアプリをホームフォルダーに置き、同期エンジンを Deck と一緒に起動するバックグラウンドサービスとして入れます。SteamOS の読み取り専用システムには何も書き込まないので、システムのアップデートで消えることはありません。

ふだんの一日

夜に PC で遊んで終了します。Hoard はゲームが閉じてセーブが動かなくなるのを待ってから、アップロードします。翌朝 Deck を手に取ります。オンラインになると、Hoard は新しいバージョンに気づいて Proton プレフィックスに書き込みます。ゲームを起動して続きを遊びます。Deck で終了すれば、同じことが逆向きに起こります。

二台が同時に電源オンである必要はありません。セーブはもう一台が取りに来るまでサーバーで待っています。

知っておきたい落とし穴

スリープは終了ではない

Deck では、電源ボタンを押してゲームを開いたまま離れるのがとても簡単です。Hoard はゲームが閉じてからしかセーブをバックアップしません。動いているゲームはセーブを書いている途中かもしれないからです。また、動いているゲームのセーブを差し替えることもありません。つまり Deck をスリープにしたまま PC で遊ぶと、Deck の進行はまだアップロードされておらず、PC の新しいセーブは Deck でゲームを閉じるまで待つことになります。

すべてを防ぐ習慣はひとつです：マシンを替える前にゲームを終了する。 終了後に Proton が死んだプロセスを残すことはよくありますが、Hoard はゲームがもういないことに気づいて処理を続けます。

復帰後は数秒待つ

Deck がスリープから復帰すると、Wi-Fi が戻るまで少しかかります。Hoard が新しいセーブを確認できるのはその後です。最初の数秒でゲームを起動すると、ダウンロードはゲームを閉じるまで待ちます。遊び始める前に、少しオンラインのまま待ってください。

microSD カード

ゲームがカード上にあり、カードが挿さっていない場合、Hoard は存在しないフォルダーにセーブをダウンロードしません。カードが戻るまで待ちます。

設定はマシンごとに残る

Deck は携帯機の GPU で 1280×800 で動きます。デスクトップはおそらく違います。Hoard は graphics.ini のような設定ファイルもセーブと一緒にバックアップしますが、もう一台の設定に上書きはしないので、Deck は自分の設定を保ちます。それでもコピーしたい場合は、復元時にそのためのオプションがあります。詳しくは 複数の PC 間でセーブを同期する方法 を参照してください。

Steam の remote フォルダー

Steam のゲームでは、セーブは userdata/<UserID>/<AppID>/remote/ にあります。その上のフォルダーには remotecache.vdf や、Deck と PC で違っていて当然のプレイ時間や実績のファイルもあります。上のフォルダーを手で同期すると、起動のたびに競合に見えます。Hoard は remote/ だけを追跡します。

Steam Cloud と Hoard の併用

互いに邪魔はしません。Steam Cloud 対応のゲームは、そのまま Steam に同期させてください。そこで Hoard が加えるのはバージョン履歴です。片方のマシンでセーブが壊れても、進行まで失われません。それ以外のゲームでは、同期も Hoard が担います。

私たちのサーバーを使わずに

セーブを家の外に出したくないなら、PC か NAS で hoard-server を動かし、Deck と PC の両方をそこに向けます。私たちのアカウントは不要、私たちへのテレメトリーもなく、私たちのサーバーを何も通りません。Hoard をセルフホストする方法 を参照してください。

よくある質問

Hoard はゲームモードで動きますか？

はい。同期エンジンは Deck と一緒に起動するバックグラウンドサービスなので、ウィンドウを開かずにバックアップと復元を行います。デスクトップモードが必要なのは、インストールとフォルダーの手動追加のときだけです。

SteamOS のアップデートで消えますか？

いいえ。Hoard がインストールするものはすべてホームフォルダーにあり、SteamOS のアップデートはそこに触れません。

Heroic、Lutris、EmuDeck のゲームも同期できますか？

はい。Hoard は Heroic、Lutris、Bottles のプレフィックスと EmuDeck のフォルダーの中を探します。検出されないゲームは、一度セーブフォルダーを指定すれば他と同じように追跡されます。

同期せずに両方で遊んでしまったら？

Hoard はやみくもに上書きしません。バージョンを比較し、置き換えるもののコピーを残し、以前のバージョンはすべて履歴に残ります。二つの別々のプレイを一つのセーブに統合することはできません（何にもできません）が、どちらを残すかは選べます。

Deck はデバイスとして数えられますか？

はい。無料プランは三台までなので、PC、ノート PC、Deck が収まります。Pro とセルフホストのサーバーには台数の制限がありません。

Deck ではコマンドライン版を使ってもいいですか？

はい。hoard コマンドはウィンドウなしで同じエンジンを動かします。携帯機ではこちらを好む人もいます。CLI のページ を参照してください。
