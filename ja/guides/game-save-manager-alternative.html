GameSave Manager の代わり：自動バックアップと同期、Linux にも対応

更新日 2026-11-05

Game Save Manager という名前のプログラムは 3 つあり、どれも Windows PC 1 台でセーブをバックアップするものです。自動でバックアップされ、ほかの PC や Steam Deck、Linux にもついてくるものが欲しいなら、Hoard は無料のオープンソースで、まさにそのために作られています。

どの Game Save Manager を使っているか

  • GameSave Manager：Windows 向けのクローズドソースの古株です。独自のゲームデータベースを持ち、手動またはスケジュールで 1 つのアーカイブにバックアップします。Sync & Link はセーブフォルダーを Dropbox、OneDrive、Google Drive に移し、元の場所にリンクを残します。
  • Game Save Manager (GSM)：dyang886 作、GPL-3.0、Windows 向け。PCGamingWiki のデータベースでインストール済みのゲームを見つけ、ゲームごとにローカルバックアップを入れ替えながら保持し、.gsmr アーカイブで履歴を新しい PC へ運べます。
  • game-save-manager：mcthesw 作、AGPL-3.0、Windows 向けで、中国語圏のコミュニティで人気があります。追加したフォルダーをスケジュールでバックアップし、WebDAV でマシンの外にもコピーを置けます。

得意なこと

  • シンプルでローカル。 ゲームを選んでバックアップを押せばアーカイブができます。アカウントも設定もいりません。
  • Windows での検出が優秀。 大きなゲームデータベースのおかげで、パスを探さなくてもほとんどのインストール済みゲームが見つかります。
  • 新しい PC へのきれいな引っ越し。 エクスポートしたアーカイブ 1 つで全部運べます。

Windows PC 1 台だけで遊び、ボタンを押すのが苦にならないなら、どれでも役目は果たせます。

Hoard がさらにできること

Game Save Manager 系 Hoard
バックアップのタイミング ボタンを押したとき、またはスケジュール ゲームがセーブするたびと、終了時にもう一度
PC 間の同期 エクスポートとインポート、または Sync & Link のクラウドフォルダー 自動：最新のセーブが次のマシンで待っています
もう 1 台の電源オフ クラウドフォルダー経由のみ 可（セーブはサーバーで待機）
履歴 ローカルバックアップ、またはクラウドドライブが残す分 すべての世代、重複排除、すべてのマシンで
書きかけのセーブ ゲームが書き込んでいる最中に、クラウドクライアントがリンク先フォルダーを同期することがある 書きかけのファイルは決してアップロードせず、動いているゲームのセーブも差し替えない
対応環境 Windows Windows、Linux、macOS、SteamOS
ライセンス クローズドソース、GPL-3.0 または AGPL-3.0 AGPL-3.0、無料

検索されているのは Linux の行です。Game Save Manager 系はどれも Linux や Steam Deck では動きません。Hoard はネイティブで動きます。4 つの OS で同じアプリが動き、Proton と Wine のプレフィックスも検出するので、Windows PC 上のゲームのセーブと、Deck 上の同じゲームのセーブは、1 つの履歴の 2 つの世代になります。

乗り換え方

  1. Hoard をインストールし、誰にでもおすすめの Hoard One にサインインするか、自分のサーバーに向けます。
  2. Sync & Link を使っていたなら、先にセーブフォルダーを元の場所に戻してください。クラウドクライアントと Hoard が同じファイルを同期しないようにするためです。
  3. ライブラリ を開きます。Hoard はコミュニティのセーブデータベースとランチャーからゲームを見つけます。見落としたフォルダーは手動で追加してください。
  4. 遊びます。ゲームがセーブするとすぐ、最初の世代が履歴に表示されます。ほかのマシンにも同じアカウントで Hoard を入れれば、PC 間の同期は自動で行われます。

以前の Game Save Manager のアーカイブは、コールドコピーとしてそのまま残しておけます。

Hoard One か、自分のサーバーか

どちらを選んでも Hoard は無料で、アプリも同じです。

  • Hoard One：すべての人におすすめです。設定することも、動かし続けるものもありません。EU にある管理サーバーで、2 GB・3 台まで無料、カードは不要です。Pro は容量を増やすだけのプランで、セーブが収まらなくなったときのために 100 GB と台数無制限を用意しています。
  • 自分のサーバー。 PC、NAS、Raspberry Pi で hoard-server を動かせば、すべてのマシンがそこを通して同期します。当方のアカウントは不要で、当方へのテレメトリーも当方による容量制限もありません。経路上に当方のものが何もないので、当方のサーバーを通るものは何もありません。Hoard をセルフホストする方法 を参照してください。

同じプログラム、同じ検出、同じ履歴です。Hoard One はすべてのバージョンをずっと保持し、自分のサーバーではどれだけ履歴を残すかを自分で決められます。

よくある質問

Linux 版の GameSave Manager はありますか？

ありません。GameSave Manager は Windows 専用で、オープンソースの 2 つの Game Save Manager も同様です。Hoard は Linux と SteamOS でネイティブに動き、Proton と Wine のプレフィックス内のセーブを見つけて、Windows PC と同期します。

Ludusavi と Game Save Manager、どちらがいいですか？

どちらもローカルバックアップのツールです。Ludusavi はオープンソースで、Windows、Linux、macOS で動き、コミュニティのセーブマニフェストを土台にしています。Game Save Manager 系は Windows 専用です。Rclone を自分で組まずにバックアップと同期を両方したいなら、Hoard は同じコミュニティのデータを使い、自動で同期します。詳しくは Ludusavi との比較 をどうぞ。

以前のバックアップは残せますか？

はい。Hoard はそれに一切触れません。アーカイブはコールドコピーとして残しておき、最初のセーブからは Hoard 自身の履歴が引き継ぎます。

Hoard は無料ですか？

はい。アプリ、コマンドライン、サーバーは無料のオープンソース（AGPL-3.0）で、自分のサーバーを動かすのにかかるのはマシン代だけです。すべての人におすすめの管理サーバーである Hoard One も 2 GB・3 台まで無料で、Pro は月 1.99 ユーロで容量を増やします。

セルフホストすると Hoard に何か送られますか？

いいえ。自分のサーバーでは当方のアカウントも当方へのテレメトリーもありません。セーブ、ユーザー、ログはあなたのマシンに留まり、当方のマシンに触れることはありません。

  • ゲームのセーブデータを自動でバックアップする方法

    ゲームがセーブするたびにPCのセーブを自動バックアップし、他のPCやSteam Deckと同期。バージョン履歴付きなので、何が起きても進行を失いません。

  • ゲームのセーブデータを新しい PC に移す方法

    新しい PC への移行や Windows の再インストール前に。すべてのセーブを持っていく方法：Steam Cloud の範囲、手作業、自動、そして落とし穴。

  • 複数の PC 間でセーブデータを同期する方法

    デスクトップ、ノートPC、Steam Deckで進行を失わずにプレイ。セーブをPC間で自動同期し、バージョン履歴も残す方法を手順で解説。
