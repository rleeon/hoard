エルデンリング（Elden Ring）のセーブデータの場所（PC・Steam Deck）

更新日 2026-10-18

PC 版のエルデンリングは、セーブデータを %APPDATA%\EldenRing\<あなたの Steam ID> に保存します。ER0000.sl2 という 1 つのファイルに、作成したすべてのキャラクター（最大 10 キャラクター）が入っています。以下では Steam Deck でのパス、フォルダーにあるほかのファイル、Seamless Co-op とナイトレインのセーブの場所、そしてすべてをバックアップしながら PC と Steam Deck で同期する方法を説明します。

エルデンリングのセーブデータの場所

  • Windows（Steam）: %APPDATA%\EldenRing\<あなたの Steam ID>\ER0000.sl2
  • Steam Deck と Linux（Proton）: ~/.local/share/Steam/steamapps/compatdata/1245620/pfx/drive_c/users/steamuser/AppData/Roaming/EldenRing/<あなたの Steam ID>/

%APPDATA% は C:\Users\<ユーザー名>\AppData\Roaming のことです。エクスプローラーのアドレスバーに %APPDATA%\EldenRing を貼り付けると直接開けます。Steam ID のフォルダーは、Steam アカウントに結びついた長い数字です。Steam Deck ではゲームは Proton で動くため、セーブは Steam が用意する Proton プレフィックスの中にあります。1245620 はこのゲームの Steam アプリ ID です。

セーブフォルダーの中身

  • ER0000.sl2 が進行状況そのものです。すべてのキャラクター、装備、ワールドでの到達地点が入っていて、SHADOW OF THE ERDTREE の分も含まれます。
  • ER0000.sl2.bak は、ゲームが隣に置くバックアップです。
  • ER0000.co2 があれば、それは Seamless Co-op MOD のものです（後述）。

グラフィック設定はこのフォルダーにはなく、1 つ上の %APPDATA%\EldenRing\GraphicsConfig.xml にあります。

このファイルの仕組みから、2 つのことが言えます。

  • キャラクターを 1 人ずつバックアップ・復元することはできません。 古い ER0000.sl2 を復元すると、直したかったキャラクターだけでなく、全キャラクターがその時点に戻ります。
  • セーブは Steam アカウントに結びついています。 ファイルの中に Steam ID が書き込まれており、別のアカウントで作ったセーブはゲームが読み込みません。自分のアカウントのセーブを、自分の PC と Steam Deck の間で移すのは問題なくできます。

Seamless Co-op とナイトレイン

Seamless Co-op

Seamless Co-op MOD は ER0000.sl2 には触れず、同じフォルダーに専用のセーブ ER0000.co2 を作ります。MOD ありとなしのキャラクターは別のファイルになるわけです。MOD のコミュニティは、オンラインで遊ぶために .co2 を通常のセーブに上書きコピーしないよう勧めています。

エルデンリング ナイトレイン

ナイトレインは別のゲームで、フォルダーも別です。Windows では %APPDATA%\Nightreign\<あなたの Steam ID>\NR0000.sl2、Steam Deck ではそのゲーム専用の Proton プレフィックス（compatdata/2622380）の中の同じパスです。エルデンリングのキャラクターに影響することはありません。

エルデンリングにクラウドセーブはありますか？

あります。Steam クラウドが、同じアカウントのマシン間で ER0000.sl2 をそろえます。ただし保持するのは最新の状態だけで、戻れる過去のバージョンはありません。またゲームの .bak はセーブと同じディスクにあるため、ディスクが壊れれば両方失われます。

手動でバックアップする

  1. ゲームを完全に終了します。
  2. %APPDATA%\EldenRing の中の Steam ID フォルダーを安全な場所にコピーします。ER0000.sl2、その .bak、あれば Seamless Co-op のセーブが入っています。
  3. 復元するときは、ゲームを終了してフォルダーを同じ場所にコピーし戻します。

Hoard で自動バックアップと同期

Hoard は無料のオープンソースです。ゲームがセーブを書くたびに、そして終了時にもう一度エルデンリングのセーブをバックアップし、いつでも戻れる履歴を残し、フォルダーを PC と Steam Deck の間で同期します。転送されるのは変更されたファイルだけで、圧縮して送られ、戻ってきたファイルはすべて SHA-256 ハッシュで照合されます。

  1. Hoard をインストールして、すべての人におすすめの Hoard One にサインインするか、自分のサーバー を指定します。
  2. ライブラリ を開きます。エルデンリングは Steam ライブラリとコミュニティのセーブデータベースから検出されます。
  3. プレイします。終了すると、最初のバージョンが履歴に表示されます。

Hoard は Steam ID フォルダーをまるごと取り込むので、Seamless Co-op のセーブもすべてのバージョンに入ります。各バージョンはその時点の全キャラクターです。戻したいときは 以前のバージョンを復元 すればよく、考えが変わっても新しいバージョンは履歴に残っています。

Hoard One か、自分のサーバーか

どちらを選んでも Hoard は無料で、アプリも同じです。

  • Hoard One：すべての人におすすめです。設定することも、動かし続けるものもありません。EU にある管理サーバーで、2 GB・3 台まで無料、カードは不要です。Pro は容量を増やすだけのプランで、セーブが収まらなくなったときのために 100 GB と台数無制限を用意しています。
  • 自分のサーバー。 PC、NAS、Raspberry Pi で hoard-server を動かせば、すべてのマシンがそこを通して同期します。当方のアカウントは不要で、当方へのテレメトリーも当方による容量制限もありません。経路上に当方のものが何もないので、当方のサーバーを通るものは何もありません。Hoard をセルフホストする方法 を参照してください。

同じプログラム、同じ検出、同じ履歴です。Hoard One はすべてのバージョンをずっと保持し、自分のサーバーではどれだけ履歴を残すかを自分で決められます。

よくある質問

エルデンリングのセーブを別の Steam アカウントで使えますか？

そのままでは使えません。ER0000.sl2 の中に Steam ID が書き込まれており、別のアカウントで作ったセーブはゲームが読み込みません。自分のアカウントの自分のセーブなら、PC と Steam Deck の間で自由に移せます。

古いセーブを復元すると、全キャラクターが巻き戻りますか？

はい。全キャラクターが ER0000.sl2 を共有しているため、どの復元でも全員がその時点に戻ります。Hoard なら新しいバージョンも履歴に残るので、巻き戻しが一方通行になることはありません。

Hoard は Seamless Co-op のセーブもバックアップしますか？

はい。MOD は通常のセーブと同じ Steam ID フォルダーに ER0000.co2 を置き、Hoard はフォルダー全体をバックアップするので、両方がすべてのバージョンに入ります。

Hoard は無料ですか？

はい。アプリ、コマンドライン、サーバーは無料のオープンソース（AGPL-3.0）で、自分のサーバーを動かすのにかかるのはマシン代だけです。すべての人におすすめの管理サーバーである Hoard One も 2 GB・3 台まで無料で、Pro は月 1.99 ユーロで容量を増やします。

セルフホストすると Hoard に何か送られますか？

いいえ。自分のサーバーでは当方のアカウントも当方へのテレメトリーもありません。セーブ、ユーザー、ログはあなたのマシンに留まり、当方のマシンに触れることはありません。

関連ガイド

  • ゲームのセーブデータを自動でバックアップする方法

    プレイ終了ごとにPCのセーブを自動バックアップし、他のPCやSteam Deckと同期。バージョン履歴付きなので、何が起きても進行を失いません。

  • 古いセーブデータを復元する方法

    セーブ破損、壊れたMod、後悔した選択。今のデータを失わずに、セーブを以前のバージョンへ戻す手順を解説します。

  • セーブデータが壊れた？復旧する方法

    読み込めないセーブも、まだ失われたとは限りません。正常なコピーの探し方（ゲーム自身のバックアップ、Steam Cloud、Windows、OneDrive）と、二度と困らないための備え。

  • Steam Deck と PC の間でセーブを同期する方法

    Steam Deck と PC のセーブを自動で同期。Steam 以外のゲーム、エミュレーター、Steam Cloud 非対応のゲームも対象です。設定手順、保存場所、落とし穴を解説。

  • Steam クラウドの代替：Steam が守らないセーブを同期して守る

    Steam Cloudは多くのゲームに非対応で履歴もありません。どのランチャーのゲームも、PCとSteam Deckの間で同期し、巻き戻せる履歴付きでバックアップ。
