セーブデータ同期ツール比較：Hoard と Ludusavi・Syncthing・OpenSave ほか

更新日 2026-11-05

Steam クラウドが守ってくれるのは Steam で買ったゲームだけ、しかも開発者が対応をオンにした場合に限られます。エミュレーター、GOG、Epic、itch.io、Steam 以外のゲーム、MOD を入れたもの——どれも対象外です。デスクトップと Steam Deck のように複数の環境で遊んでいると、結局フォルダーを手でコピーして、新しいほうを掴んだと信じるしかなくなります。

これを解決するツールはいくつもありますが、やっていることは同じではありません。ローカルにバックアップを取るもの、端末間でフォルダーをミラーするもの、クラウドへアップロードするもの。このページではそれぞれを見ていき、何が本当に得意なのかを書きます。Hoard は私のプロジェクトなので最後に置き、Hoard がしないことと、本文を一切信じなくても読める比較表を添えました。

Ludusavi

いちばん有名で、それも当然の一本です。Ludusavi（作者は mtkennerly）は GUI と CLI を備えた無料のオープンソースのバックアップツールで、何万本ものゲームのセーブ位置を収録したコミュニティ製マニフェストの上に成り立っています。このページのほとんどのツール（Hoard も含む）が使っているのと同じマニフェストです。ローカルにバージョン付きのバックアップを保持し、Rclone を設定すれば自分のクラウドへ送れます。

向いているのは： ローカルのバックアップと完全な制御が欲しくて、サーバーはどこにも置きたくない人。このリストで最も安全な選択で、しかも無料です。

足りないところ： 端末間の同期は自分で組み立てるものになります。バックアップを予約し、Rclone のリモートを設定し、遊ぶ前に別の PC で復元するのを忘れない。動きはしますが、最後の一手を忘れるのを止めてくれるものは何もありません。

Syncthing

そもそもゲーム用ではなく、汎用の P2P フォルダーミラーで、しかも良い出来です。セーブフォルダーを指定すれば、ほかの端末にも現れます。

向いているのは： すでに動かしていて、クラウドを挟まずにファイルを二か所に置きたい人。

足りないところ： ミラーであって、スナップショットではありません。壊れたセーブも、正常なセーブとまったく同じ速さで数秒のうちに全端末へ届きます。ファイル単位のバージョン管理はありますが、プレイセッションという概念はないので、「火曜の夜の状態に戻す」は手作業で組み直すことになります。両方の端末がオフラインで遊んでいれば、返ってくるのは競合ファイルであってマージではありません。

OpenSave

セーブデータ専用に作られた P2P 同期。Go 製、MIT ライセンス、Windows・Linux・Steam Deck に加え、バージョン 2.4 からは macOS にも対応しています。アカウントもサーバーも不要で、端末同士をペアリングして LAN 経由、あるいはリレーのルームコード経由で同期します。変更のたびにスナップショットを取り、並行プレイ用のブランチがあり、競合は時計ではなく同期の系譜で解決し、転送は変化したブロックだけ。任意で Drive・Dropbox・OneDrive・WebDAV へのミラーもできます。

向いているのは： アカウントは絶対に作りたくなくて、端末が同時に起動している機会が十分にある人。

足りないところ： P2P である以上、セーブはあなたの端末の上にしか存在しません。最新のコピーを持っていた Deck が壊れ、ミラーを設定していなければそれで終わりです。同期には両方の端末が動いている必要があります。

OpenCloudSaves

すでに料金を払っているクラウド——OneDrive、Google Drive、Dropbox、Nextcloud——へセーブフォルダーを同期する、マルチプラットフォームの GUI です。中身は Rclone です。

向いているのは： すでに持っているストレージにセーブを置きたくて、Rclone の設定ファイルではなく画面で操作したい人。

足りないところ： プロジェクトは 2025 年 1 月にアーカイブされ、もうメンテナンスされていないため、新しいゲームやシステム更新への修正は入りません。そのうえ、内容ベースの重複排除がありません。2 GB のセーブが 10 世代あれば Drive の容量を 20 GB 食いますし、クラウドドライブが同期するのはファイルであってプレイセッションではないので、戻ってくるのは「その時点のフォルダーの姿」だけです。

Game Backup Monitor

Windows 中心で、このジャンルの元祖です。GBM はゲームのプロセスを見張り、終了した時点でセーブを 7-Zip で圧縮し、連番の履歴として残します。

向いているのは： Windows PC 一台で、何も考えずに圧縮済みのローカルアーカイブが欲しい人。

足りないところ： バックアップのツールであって同期のツールではありません。アーカイブを二台目に持っていくのは自分の仕事ですし、Steam Deck / SteamOS は得意分野ではありません。

GameSave Manager

長く使われてきた無料の Windows 用ツールで、クローズドソース、独自のゲームデータベースを持っています。バックアップと復元ができ、最もよく知られた機能 Sync & Link は、セーブフォルダーを Dropbox や OneDrive などのクラウドフォルダーに移し、元の場所にリンクを残して、クラウドクライアントに同期させます。

向いている人: Windows を使っていて、すでに Dropbox や OneDrive 中心で暮らしており、セーブがそこにあればいい人。

限界: Windows のみ。また Sync & Link では、ゲームが書き込んでいる最中の使用中フォルダーを汎用クラウドクライアントが同期します。これは Syncthing がセーブに危険な理由と同じパターンです。バージョン履歴はクラウドドライブが保持する分だけです。

Game Save Manager (GSM)

名前は似ていますが、上のものとは別のプログラムです。dyang886 による GSM は GPL-3.0 の Windows アプリで、PCGamingWiki のデータベースを使って Steam、Epic、Battle.net などのランチャーからインストール済みのゲームを見つけ、ゲームごとに上限を決めたローカルバックアップを入れ替えながら保持し、エクスポートした .gsmr アーカイブで履歴ごと新しい PC へ移せます。さらに 3 つ目の同名ツールもあります。mcthesw の game-save-manager で、中国語圏のコミュニティで人気があり、手動で追加したフォルダーを定期的にバックアップし、WebDAV でマシンの外にもコピーを置けます。

向いているのは： Windows PC 1 台で遊び、ほぼ設定なしで世代付きのローカルバックアップが欲しく、新しいマシンへの引っ越しも簡単にしたい人。

足りないところ： 端末間の同期はありません。2 台目の PC にセーブを届けるには、アーカイブをエクスポートしてそちらでインポートします。Windows 専用です。

SaveState

Matteo842 による SaveState は、Windows と Linux 向けの GPL-3.0 のバックアップマネージャーで、別途 Android 版アプリもあります。ランチャーのショートカットをドロップするとセーブフォルダーを見つけてくれ、エミュレーター対応も充実しています。RetroArch、Dolphin、PCSX2 のメモリーカード、xemu のほか 20 種類以上です。バックアップはローテーションする圧縮 .zip アーカイブで、オプションのクラウド同期で Google Drive、WebDAV、FTP、ネットワーク共有、Git へコピーできます。

向いているのは： エミュレーターに強い、とっつきやすいバックアップツールが欲しく、もう 1 台では手動で復元しても構わない人。

足りないところ： 中心にあるのは生きたセーブではなくバックアップのアーカイブです。同期はそのアーカイブをマシン間で動かしますが、向こう側でゲームのフォルダーに戻すのは、自分で実行する復元のままです。macOS 版はありません。

EmuSync

EmuSync は PC とエミュレーターのセーブ向けの GPL-3.0 の同期ツールで、まず Windows PC と Steam Deck のために作られています。各端末での各ゲームのセーブ位置を、自分の Google Drive、Dropbox、OneDrive、または共有フォルダー上の 1 つの同期ポイントに対応付け、自動または手動で同期します。Decky プラグインでゲームモードから状態を確認できます。

向いているのは： Windows PC と Deck の間で遊び、すでに持っているクラウドドライブにセーブを置きたい人。

足りないところ： クラウドに置かれるのは現在の状態で、バックアップと復元は端末間で共有される履歴ではなく各端末のローカルです。macOS は未検証で、最新リリースは 2026 年 2 月です。

Aletheia

比較的新しいツールで、AGPL。ほかが中途半端にしか押さえていない部分、つまりランチャーを正面から狙っています。Heroic、itch.io、Lutris、Steam、GOG Galaxy、Xbox に、Windows・Linux・macOS 対応。

向いているのは： ライブラリが、ほかのツールでは検出しづらいランチャー——とくに Xbox / Game Pass と Heroic——に散らばっている人。

足りないところ： 意図的に範囲を絞った若いプロジェクトです。機能はバックアップと復元まで。背後にバージョン管理されたクラウドがあるわけではありません。

SaveSync

唯一の商用で、Steam で買い切り販売、Windows 中心。特徴は、狙いが「二台の PC を使う自分」ではなく協力プレイにあることです。セーブは非公開・非掲載の Steam ワークショップの項目として保存され、友達があなたの Valheim や Factorio のワールドを持っていけます。LAN 同期もあります。

向いているのは： 解決したい問題が「自分のセーブについてきてほしい」ではなく「友達がホストで、その人のセーブが要る」である人。

足りないところ： クローズドソース、Windows、転送路として Steam に依存、そして対応するのは所有物すべてではなく協力プレイ向けの対応ゲーム一覧です。

Tachyon

このリストで最も新しい名前で、Windows 向けの無料ベータ版です。5,000 本以上の PC ゲームのセーブを検出し、自社のクラウド経由で同期し、複数の「タイムライン」を持つバージョン履歴を保持します。

向いている人: Windows を使っていて、すぐに動くものがほしく、ベータ版でも気にならない人。

限界: 現時点では Windows のみ（Linux と macOS は「近日対応」とされています）なので Steam Deck はまだ使えません。ソースコードは公開されておらず、自分のサーバーで運用する方法もありません。ベータ終了後の価格は発表されていません。

Steam Deck 用プラグイン（Decky）

Deck 本体では、いくつかの Decky Loader プラグインがゲームモードから作業の一部を担います。Decky Cloud Save はゲームを閉じたあとに rclone でフォルダーを OneDrive、Google Drive、Dropbox と同期しますが、作者はもうメンテナンスしておらず、2 つの後継を案内しています。Decky Ludusavi（ゲームモード用の Ludusavi フロントエンド）と、SDH-GameSync（各ゲームの起動時にセーブを取得し、終了時にアップロードするフォーク）です。Steamback は Steam クラウドを使うゲームについて、終了時に取ったローカルのスナップショットを直近 10 個保持します。

向いているのは： 主に Deck で遊び、ゲームモードから離れずに操作できるものが欲しい人。

足りないところ： どれも Deck 専用で、端末間の部分は別のものに頼っています。rclone とクラウドドライブ、Ludusavi、あるいは Steam クラウドそのものです。Steamback のスナップショットは Deck に残り、Steam クラウド対応ゲームしか対象になりません。

EmuDeck についての注記

この手の話題では EmuDeck も名前が挙がりますが、通常の意味での競合ではありません。Steam Deck 向けのエミュレーターのインストーラー兼設定ツールであり、備わっている同期はその仕事に付け足された利便機能です（クラウドドライブに対する Rclone、しかもエミュレーターのセーブ限定）。上のツール群と重なる部分はあっても、同じ種類のものではありません。EmuDeck はエミュレーター環境を整えるもの、ここで挙げたものはライブラリ全体のセーブを見守るもの。EmuDeck とどれか一つを併用している人もいて、それは重複ではなく理にかなった構成です。

Hoard

Hoard は、ゲームがセーブを書き終えた時点でそれをバックアップし、遊ぶすべてのマシンで同期を保ちます。エンジンはバックグラウンドサービス hoardd としてウィンドウなしで動くので、SteamOS のゲームモードでも動き続けます。フォルダーが数秒間静かになるのを待つため、書きかけのファイルをアップロードすることはありません。終了時にもう一度コピーを取り、動いているゲームのセーブを差し替えることもありません。別のマシンから届いたものは、ゲームを閉じるまで待ちます。

  • もう 1 台は電源が切れていてもかまいません。 最新のセーブはサーバーで待っているので、来週手に取る Deck は PC が起動していなくてもそれを受け取れます。ピアツーピアのツールは、両方の端末が同時に起きている必要があります。
  • すべての世代を保持。 セーブのひとつひとつが、アプリや hoard restore で戻れる世代になります。ディスク故障やクリーンインストールの後でも同じです。Hoard One はすべての世代を無期限に残し、自分のサーバーではどれだけ履歴を残すかを自分で決められます。
  • 送るのは変わった分だけ。 アップロードでは変更されたファイルだけを zstd で圧縮して送り、世代どうしは変わっていない部分を共有します。ほとんど変わらない 2 GB のセーブを 10 世代残しても、使うのは 20 GB ではなく約 2 GB です。
  • 行きも帰りも SHA-256。 破損は正常なセーブを上書きする前に検出され、Hoard は置き換えるものすべてのコピーを残します。
  • 無料でオープンソース。自分のサーバーも選べます。 アプリ、CLI、サーバーはすべて AGPL-3.0 です。誰にでもおすすめしているマネージドサーバー Hoard One は 2 GB・3 台まで無料で、準備は何もいりません。あるいは PC、NAS、Raspberry Pi で Docker を使って hoard-server を動かし、ローカルディスクか S3 互換ストレージに保存することもできます。当方のアカウントも、当方へのテレメトリーも、当方の容量制限もありません。
  • Windows、Linux、macOS、SteamOS の 4 つで同じデスクトップアプリが動き、サーバーや画面のないマシン向けに CLI もあります。
  • ライブラリ全体をカバーする検出： Steam、Epic、GOG、Proton と Wine のプレフィックス、コミュニティのセーブデータベースによる数千本のゲーム、そして PCSX2、Dolphin、RPCS3 から Ryujinx、Cemu、DuckStation、RetroArch まで 19 種類のエミュレーターのプリセット。

Steam Deck ↔ PC の同期を左右する細部

どのツールを選ぶにしても知っておく価値があります。Steam のゲームのクラウドセーブは <AppID>/remote/ にあり、その一つ上のフォルダーには remotecache.vdf、実績の状態、統計、プレイ時間のカウンターが入っています。これらは Deck とデスクトップとで違っていて当たり前のものです。

親フォルダーを同期すれば、セーブについては一度も食い違っていない二台の間で、恒久的な競合が起きます。Hoard が追いかけるのは remote/ であって親フォルダーではありません。フォルダーを手動で指定できるツールなら同じ設定にできますし、同期の構成が理由もなく競合を出し続けるときに最初に確認すべき点でもあります。

Hoard がしないこと

  • サーバーなしの同期。 Hoard は必ずサーバーを経由して同期します。何も動かしたくなければ Hoard One、そうでなければ自分のサーバーです。だからこそもう 1 台の電源が切れていても同期でき、2 台とも壊れても残るコピーができます。どうしてもサーバーを使いたくないなら、OpenSave、Syncthing、Ludusavi がそのために作られています。
  • 協力プレイのワールド共有。 友達にワールドを渡すのは SaveSync の役目で、Hoard が守るのはあなた自身のセーブです。
  • 分岐した 2 つのセーブの統合。 2 つのプレイを 1 つにまとめられるツールはありません。Hoard は両方を世代として、すべてのマシンに残し、どちらにするかはあなたが選びます。

Hoard One とセルフホストの違い

Hoard についての比較は、ほぼ必ずこの 2 つを一緒くたにし、その結果として誤った説明になります。はっきり書いておきます。

  • Hoard One はマネージドな選択肢で、すべての人におすすめです。サインインすると、セーブは EU にある当方のサーバーに保存されます。
  • セルフホストした Hoard は完全にあなたのものです。 自分の PC や NAS で hoard-server を動かせば、セーブは自分のマシンから自分のディスクへ移ります。当方のアカウントも、当方へのテレメトリも、容量制限も、中継もありません。 経路上に当方のものが何一つないため、当方のサーバーを何も通りません。セーブもゲーム名もメールアドレスも見えません。届かないからです。仮に明日 Hoard One が終了しても、セルフホスト構成はそのまま動き続けます。

同じコード、同じ検出。変わるのは保存先が誰のものかと、既定の設定がひとつ。セルフホストのサーバーは、オフにしない限り古い世代を時間とともに間引きます。正確を期して 1 点だけ補うと、あなたのサーバーには確かに自前のログイン、つまりユーザーと端末ごとのトークンがありますが、それらはあなたのデータベースの中にあり、当方のデータベースにはありません。

で、どれを選ぶか

PC と Steam Deck の間で、バックアップと同期を勝手に済ませてほしい。すべての世代を残し、もう 1 台は電源を切ったままでよく、全部を自分のものにする選択肢も欲しい。それなら Hoard です。ダウンロードして Hoard One にサインインするか、先に Docker でのセルフホスト方法 を読んでください。どちらでも無料です。

もっと限られた用途なら次のとおりです。Windows PC 1 台でローカルアーカイブだけなら Game Backup Monitor か GSM。サーバーをどこにも置かず、完全に自分で管理するローカルバックアップなら Ludusavi。どうしてもアカウントを作りたくなく、端末がたいてい同時に起動しているなら OpenSave か Syncthing。すでに料金を払っている Drive のフォルダーにセーブを置く必要があるなら、Rclone リモート付きの Ludusavi か EmuSync。OpenCloudSaves もそれをしていましたが、アーカイブされています。友達と協力プレイのワールドを共有するなら SaveSync。

OpenCloudSaves から来た人で、欲しかったのが Drive そのものではなく自分で管理できるストレージなら、セルフホストの Hoard がそれを履歴付きで実現します。ローカルディスクか、Backblaze B2 や MinIO のような S3 互換バケットに書き込めます。Ludusavi と比べているなら、Ludusavi とのより詳しい比較 もあります。

よくある質問

この中で世代履歴を残すのはどれですか？

Hoard はセーブのたびに 1 世代として、すべてのマシンに残し、そこへ戻れます。Ludusavi、GSM、SaveState は世代付きまたはローテーションするローカルバックアップを保持し、OpenSave は自分の端末にスナップショットを残します。その他の多くは現在の状態を同期・コピーするだけなので、壊れたセーブはそのまま忠実にもう 1 台へ伝わります。

サーバーもアカウントもなしで使えるのはどれですか？

ローカルバックアップとしての Ludusavi と、ピアツーピアのツール全般です。セルフホストするなら Hoard も該当します。当方のアカウントはなく、当方のサーバーを通るものもありません。

もう 1 台の電源が切れていても同期できるのはどれですか？

自分の端末以外の場所にセーブを置くツールです。Hoard（Hoard One または自分のサーバー経由）と、EmuSync や Rclone 付きの Ludusavi のようにクラウドドライブへ書き込むツールです。ピアツーピアの同期（ミラーなしの OpenSave、Syncthing）は、両方の端末が同時に起動している必要があります。

Steam にないゲームをカバーするのはどれですか？

ここに挙げたセーブ管理ツールはすべてカバーします。ストア経由ではなく、同じコミュニティのデータベースでセーブの場所を突き止めるからです。例外は Steam クラウドで、開発者が有効にした Steam のゲームしか対象になりません。

1 つだけ選ばないといけませんか？

いいえ。実際、多くの人は選んでいません。ローカルバックアップのツールと同期のツールは、問題の別々の半分を解いています。唯一の注意は、一方をもう一方のバックアップフォルダーに向けないこと。向けると、実際のセーブではなく古い写しを同期することになります。

自作構成がいちばん壊れる原因は何ですか？

Steam の userdata にある <AppID>/remote/ の 1 つ上のフォルダーを同期することです。上のフォルダーには remotecache.vdf や、マシンごとに違って当然の実績・プレイ時間のファイルが入っているため、セーブが動いていなくても起動のたびに競合に見えます。

関連ガイド

  • Ludusavi の代替：セーブデータの自動クラウド同期

    Ludusaviはローカルバックアップに最適。HoardはPCとSteam Deck間の自動同期とバージョン履歴を、同じセーブ場所データベースの上に追加します。

  • Steam クラウドの代替：Steam が守らないセーブを同期して守る

    Steam Cloudは多くのゲームに非対応で履歴もありません。どのランチャーのゲームも、PCとSteam Deckの間で同期し、巻き戻せる履歴付きでバックアップ。

  • Syncthing でセーブデータを同期する：うまくいく点と壊れる点

    Syncthingは優れた同期ツールですが、セーブデータはその3つの前提を崩します。何が起きるか、回避策、専用ツールが向く場面を解説。

  • GameSave Manager の代わり：自動バックアップと同期、Linux にも対応

    GameSave Manager の代わりを探しているなら。Hoard はセーブを自動でバックアップし、PC と Steam Deck の間で同期し、Linux と macOS でも動きます。

  • OpenCloudSaves の代わり：アーカイブされた今、何を使うか

    OpenCloudSaves は 2025 年 1 月にアーカイブされました。Hoard は保守が続くオープンソースの代替で、自動で同期し、すべての世代を残します。

  • SaveSync の代わり：すべてのゲームに使える無料・オープンソースのセーブ同期

    SaveSync の無料の代わりを探しているなら。Hoard は協力プレイ用だけでなく全ゲームのセーブを、Windows、Linux、macOS、Steam Deck で同期します。
