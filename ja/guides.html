セーブデータのバックアップと同期のガイド

Hoard を最大限に活用するための実践的なステップバイステップガイド。すべての PC でセーブデータをバックアップ・同期・復元できます。

  • DockerでHoardをセルフホストする方法

    Docker ComposeでHoardサーバーを自前で運用し、すべてのデバイスのセーブをそこで同期。無料・オープンソースで、当社のアカウントも容量制限も不要です。

  • ゲームのセーブデータを自動でバックアップする方法

    プレイ終了ごとにPCのセーブを自動バックアップし、他のPCやSteam Deckと同期。バージョン履歴付きなので、何が起きても進行を失いません。

  • 複数の PC 間でセーブデータを同期する方法

    デスクトップ、ノートPC、Steam Deckで進行を失わずにプレイ。セーブをPC間で自動同期し、バージョン履歴も残す方法を手順で解説。

  • 古いセーブデータを復元する方法

    セーブ破損、壊れたMod、後悔した選択。今のデータを失わずに、セーブを以前のバージョンへ戻す手順を解説します。

  • セーブデータ同期ツール比較：Hoard と Ludusavi・Syncthing・OpenSave ほか

    Hoard、Ludusavi、Syncthing、OpenSave、GameSave Managerなどを比較。それぞれの強みと弱点、並べて見られる比較表付き。

  • Ludusavi の代替：セーブデータの自動クラウド同期

    Ludusaviはローカルバックアップに最適。HoardはPCとSteam Deck間の自動同期とバージョン履歴を、同じセーブ場所データベースの上に追加します。

  • エミュレーターのセーブをバックアップ・同期する方法（RetroArch、Dolphin、PCSX2）

    RetroArch、Dolphin、PCSX2、DuckStationなどのエミュレーターのセーブをPCとSteam Deck間でバックアップ・同期。履歴付き、保存場所の一覧も。

  • Steam クラウドの代替：Steam が守らないセーブを同期して守る

    Steam Cloudは多くのゲームに非対応で履歴もありません。どのランチャーのゲームも、PCとSteam Deckの間で同期し、巻き戻せる履歴付きでバックアップ。

  • OpenSave の代替：端末間の直接転送か、自分のサーバーか

    OpenSaveはP2Pで同期、Hoardは自前または当社のサーバー経由で同期し全バージョンを保持。どちらの設計が向くかを公平に解説。

  • Syncthing でセーブデータを同期する：うまくいく点と壊れる点

    Syncthingは優れた同期ツールですが、セーブデータはその3つの前提を崩します。何が起きるか、回避策、専用ツールが向く場面を解説。

  • Steam Deck と PC の間でセーブを同期する方法

    Steam Deck と PC のセーブを自動で同期。Steam 以外のゲーム、エミュレーター、Steam Cloud 非対応のゲームも対象です。設定手順、保存場所、落とし穴を解説。

  • PC ゲームのセーブデータはどこにある？主な保存場所の一覧

    Windows、Steam Deck、Linux、Mac で PC ゲームがセーブを保存する場所、独自フォルダーを使うランチャー、どんなゲームのセーブでもすぐ見つける方法。

  • セーブデータが壊れた？復旧する方法

    読み込めないセーブも、まだ失われたとは限りません。正常なコピーの探し方（ゲーム自身のバックアップ、Steam Cloud、Windows、OneDrive）と、二度と困らないための備え。

  • ゲームのセーブデータを新しい PC に移す方法

    新しい PC への移行や Windows の再インストール前に。すべてのセーブを持っていく方法：Steam Cloud の範囲、手作業、自動、そして落とし穴。

  • RetroArch のセーブを PC と Steam Deck で同期する方法

    RetroArch のセーブとステートを PC、Steam Deck、ノート PC 間で同期。.srm の保存場所、内蔵の Cloud Sync と自動同期の違い、落とし穴。

  • OneDrive とゲームのセーブ：何が壊れ、どう直すか

    OneDrive がドキュメントを移し、セーブが失敗したり消えたり重複したり。その理由、直し方、そしてゲームのセーブをもっとうまく同期する方法。

  • PCSX2 のクラウドセーブ：PS2 のメモリーカードを PC と Steam Deck で同期する

    PCSX2 にはクラウドセーブがありません。PS2 のメモリーカードを PC と Steam Deck の間で自動同期し、履歴も残す方法。保存場所、フォルダー型カード、落とし穴。

  • Dolphin のクラウドセーブ：ゲームキューブと Wii のセーブを PC と Steam Deck で同期する

    Dolphin にはクラウドセーブがありません。ゲームキューブと Wii のセーブを PC と Steam Deck の間で自動同期し、履歴も残す方法。保存場所、カードの種類、落とし穴。

  • デュアルブート PC で Windows と Linux のセーブを同期する方法

    一台の PC、二つのシステム、二つのセーブフォルダー。Windows と Linux の間でセーブを自動同期する方法、共有 NTFS フォルダーが失敗する理由、そして落とし穴。

  • ROG Ally、Legion Go、MSI Claw と PC の間でセーブを同期する方法

    ROG Ally、Legion Go、MSI Claw のような Windows 携帯機は、中身は PC です。デスクトップとセーブを自動で同期し、バージョン履歴も残す方法。

  • Epic と GOG のクラウドセーブ：対応範囲と、残りを同期する方法

    Epic と GOG のクラウドセーブは一部のゲームだけ、各ランチャーの中だけで、履歴もありません。何をカバーし、残りをどう自動同期するか。

  • サイバーパンク2077（Cyberpunk 2077）のセーブデータの場所（PC・Steam Deck）

    Cyberpunk 2077のセーブデータがWindows、Steam Deck、Macのどこにあるか、各フォルダーの中身、バックアップとPC間での同期のしかたを解説。

  • 紅の砂漠（Crimson Desert）のセーブデータの場所（PC・Steam Deck）

    Crimson DesertのセーブデータがWindows、Steam Deck、Macのどこにあるか、実際にセーブが入っているフォルダー、バックアップとPC間での同期のしかたを解説。

  • Marvel's Spider-Man 2 のセーブデータの場所（PC・Steam Deck）

    Marvel's Spider-Man 2のPC版セーブデータの場所、長い数字のフォルダーの正体、OneDriveの落とし穴、Steam Deckでのパス、バックアップと同期の方法を解説。

  • バルダーズ・ゲート3（Baldur's Gate 3）のセーブデータの場所（PC・Steam Deck）

    Baldur's Gate 3のセーブデータがWindows、Steam Deck、Macのどこにあるか、セーブとModや設定の違い、オナーモード、バックアップと同期の方法を解説。

  • パルワールド（Palworld）のセーブデータの場所（PC・Steam Deck）

    PalworldのワールドがPCとSteam Deckのどこに保存されるか、各ファイルの役割、協力プレイのワールドのしくみ、バックアップとPC間での同期のしかたを解説。
