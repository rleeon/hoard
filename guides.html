Game save backup & sync guides

Practical, step-by-step guides to back up, sync and restore your game saves on every PC — Steam, emulators (RetroArch, Dolphin, PCSX2) and more. Hoard reads the same community save-location data as Ludusavi, then adds automatic cloud sync and versioned history on top.

  • How to self-host Hoard with Docker

    Run your own Hoard server with Docker Compose in minutes. Open source, free, on your hardware — a fully self-hosted cloud for your game saves, no account or quota.

  • How to back up your game saves automatically

    Set up automatic, versioned cloud backups for your PC game saves with Hoard — so a crash, reinstall or bad mod can never wipe your progress.

  • How to sync game saves across multiple PCs

    Play the same game on your desktop and laptop without losing progress. Sync your game saves across PCs automatically with Hoard — managed cloud sync without wiring up Ludusavi and Rclone by hand.

  • How to restore an old game save

    Made a wrong move, corrupted a file or want a fresh start? Roll back to any previous version of your game save with Hoard's cloud history — including saves backed up by tools like Ludusavi.

  • Game save sync compared: Hoard vs Ludusavi, Syncthing, OpenSave and the rest

    An honest comparison of the tools that back up and sync PC game saves — Ludusavi, Syncthing, OpenSave, OpenCloudSaves, Game Backup Monitor, Aletheia, SaveSync and Hoard — with a table, and a section on where Hoard loses.

  • Ludusavi alternative: automatic cloud sync for your game saves

    A fair comparison of Ludusavi and Hoard. Ludusavi is a great open-source local backup tool; Hoard adds managed cloud sync and versioned history across all your PCs — using the same save-location data.

  • How to back up and sync emulator saves (RetroArch, Dolphin, PCSX2)

    Back up and sync your emulator save files and save states across PCs — RetroArch, Dolphin, PCSX2, DuckStation and more — automatically with Hoard.

  • Steam Cloud alternative: back up the saves Steam doesn't

    Steam Cloud only covers Steam games whose developer switched it on, and it keeps no version history. Hoard backs up every game you play, from any launcher, with a versioned history you can roll back — in the cloud or on your own server.

  • OpenSave alternative: peer-to-peer or a server you own

    OpenSave syncs game saves directly between your PCs, with no server in the middle. Hoard syncs through a server — ours or one you host — and keeps a versioned history. An honest look at when each design wins.

  • Syncthing for game saves: what works and what breaks

    Syncthing is an excellent general-purpose file syncer, but game saves break three of its assumptions. What goes wrong, how people work around it, and when a save-aware tool is the better answer.
