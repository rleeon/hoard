如何把游戏存档转移到新电脑

更新于 2026-10-09

支持 Steam 云的游戏，在新电脑上登录后会自己回来。其余的都是你得自己搬的文件夹：没有云存档的游戏、模拟器、Steam 之外的任何东西。你可以手动复制这些文件夹，也可以让 Hoard 在旧电脑上备份它们，再在新电脑上把每一个放回正确的位置。下面介绍两种方法，以及让人丢掉存档的那些陷阱。

在删除任何东西之前

  • 列出你在玩的游戏，包括几个月没碰过的。被遗忘的往往就是它们。
  • 确认哪些游戏有云存档。 在 Steam 上，商店页面会写明，属性 → 通用 里能看到是否开启。Epic 和 GOG 也会逐个游戏显示。
  • 备份其余的，最好全部备份。 云存档只保留一份副本，也就是最新的那份。如果它坏了，那在哪里都是坏的。

手动方法

  1. 找到每款游戏的文件夹。 大多数在 Documents\My Games、Saved Games 或 AppData 文件夹（Roaming、Local、LocalLow）里。完整列表见 PC 游戏的存档在哪里。
  2. 复制到外接硬盘，保持文件夹结构不变。把 Steam 的整个 userdata 文件夹也带上：它很小，能覆盖那些通过 Steam 存档却没开 Steam 云的游戏。
  3. 在新电脑上先安装游戏。 如果游戏需要先创建自己的文件夹，就启动一次，在主菜单退出。不要开新游戏。
  4. 把存档复制到对应位置 再启动。在删除旧硬盘上的任何东西之前，确认进度都在。

这样可行。缺点是它只是一次性的复制：你得记住每个文件夹，而且如果你继续在旧电脑上玩，从那天起两边就会分道扬镳。

陷阱

  • 与账户绑定的存档。 有些游戏会把账户 ID 放进文件夹名或存档里：Elden Ring 按 SteamID 存放存档，育碧的游戏按 Ubisoft ID。两台电脑用同一个账户：没问题。换了账户：游戏看到的是空存档位。
  • OneDrive 移动了文档文件夹。 如果一台电脑用 OneDrive 备份 文档，另一台没有，那“同一个”文件夹就在两个不同的地方。右键点击 文档，打开 属性 → 位置，看看它到底在哪。更多内容见 OneDrive 与游戏存档。
  • 游戏版本。 较新版本的存档可能在旧版本里读不出来。复制之前先在新电脑上更新游戏。
  • 模组。 带模组的存档（尤其是 Bethesda 的游戏）没有相同的模组可能无法加载。先把模组装回来。
  • 从 Windows 到 Steam Deck 或 Linux。 存档要放进游戏的 Proton 前缀里，而前缀只有在游戏启动过一次之后才存在。参见 如何在 Steam Deck 和 PC 之间同步存档。

自动方法

对 Hoard 来说，搬家和它每天做的事一样：在一台机器上备份，在另一台上还原。

  1. 在旧电脑上 安装 Hoard 并登录。打开 库：Hoard 会列出它为你的游戏找到的存档，用的是和 Ludusavi 相同的社区数据库。缺少的，指定文件夹添加即可。
  2. 确认每款游戏的历史里都有一个版本。 查看它的 历史。这是你清空旧硬盘之前的安全网。
  3. 在新电脑上 安装 Hoard，用同一个账户登录，再安装你的游戏。Hoard 会按游戏把它们和备份对应起来，并把最新版本还原到这台机器期望的文件夹，即使路径不同（另一块硬盘、另一个用户名、Deck 上的 Proton 前缀）也一样。
  4. 开新游戏之前，先让 Hoard 把存档放回去。应用里会显示每款游戏的状态。

有两个细节让它比复制更安全。graphics.ini 这类设置文件会被备份，但不会覆盖新电脑上的设置，所以新硬件会以适合它的设置启动（如果两台机器差不多，还原时也可以把设置一起带过来）。而且没有什么是不可挽回的：每个版本都留在历史里，还原错了，还原前一个版本就能撤销。

如果旧电脑还要继续用，它会继续和新电脑同步。如果要永久淘汰，就把它从你的设备里移除。免费方案包含三台。

不用我们的服务器

这一切都可以用你自己的服务器完成：在 PC 或 NAS 上运行 hoard-server，把两台机器都指向它，存档就永远不会离开你家。不需要我们的账户，没有发给我们的遥测。参见 如何自托管 Hoard。

常见问题

Steam 的存档会自动转移吗？

只有支持 Steam 云的游戏会。在新电脑上登录、安装游戏，存档就会下载。不支持的游戏需要复制它们的文件夹，或者用一个替你完成的工具。

我能直接复制整个用户文件夹吗？

对大多数存档有效，但也会把好几 GB 的缓存、为旧硬件准备的设置，以及可能在新系统上惹麻烦的应用数据一起带过去。只复制存档文件夹更干净。

Windows 用户名不一样，存档还能用吗？

能，几乎总是。存档是相对于你的用户文件夹存放的，路径里的名字无关紧要。Hoard 会自动处理。

能把存档从 Windows 转到 Steam Deck 吗？

能。先在 Deck 上启动一次游戏，让它的 Proton 前缀生成，然后把存档放进去，或者交给 Hoard。参见 Steam Deck 指南。

新电脑准备好之前，需要保留旧电脑吗？

手动复制的话，在检查完每款游戏之前留着外接硬盘。用 Hoard 的话，存档已经在服务器上，所以只要每款游戏的历史里都显示有版本，旧电脑就可以处理掉了。
