1. 同步

在台式机上开始，在笔记本上继续。

当你关闭游戏时，Hoard 上传存档；当你打开另一台电脑时，它会拉取较新的版本。无需复制文件夹，无需 U 盘，也不会用旧存档覆盖好存档。

  • 自动：它会察觉你何时停止游戏并自行同步。
  • 感知冲突：如果两台机器出现分歧，最新的胜出，另一份在本地备份。
  • 万一出了问题，可以从应用内回滚到任意较早的版本。

2. AI

想用的话，也能配合你的 AI 智能体。

Hoard 自己就能完成所有工作；AI 只是可选的额外功能。如果你已经在用 opencode、Claude Code 或 Codex 这样的智能体，Hoard 自带的技能能让它读取你的存档、找出问题并提出修复方案。

  • 可选：从不使用它，Hoard 也照常工作。
  • Hoard 内部没有 AI：智能体由你自带，云端或本地均可。
  • 每次恢复或删除都要等你同意。

3. 如何开始

三步。无需设置。

装好应用，登录一次，然后忘掉它的存在。

01

安装并登录

下载适用于你系统的应用，用 Google 或邮件链接登录。开机自启，常驻托盘。

免费下载
02

检测你的游戏库

Hoard 在 Steam、Epic、GOG、Proton/Wine 前缀等处找到你的游戏，并自行跟踪。通过 Ludusavi 清单支持数千款游戏。

03

同步与历史

每次你停止游戏，都会创建一个快照并同步到你的其他机器。可从游戏库回滚到任意版本。

4. 你能获得什么

像工具一样打造，而非一句承诺

下面的一切如今都已在产品中，两个套餐都有。

跨设备同步

你的存档从台式机跟到笔记本。最新版本胜出，另一份在本地备份。

每次备份都是一个快照

历史在任何套餐都不会过期。可回到三周、三个月、三年前。

每个文件都有 SHA-256

按内容寻址的快照，恢复时重新哈希。静默损坏会被捕捉。

自行识别你的游戏库

通过 Ludusavi 清单支持数千款游戏，并对 Steam、Epic、GOG、Proton、Wine、Lutris、Bottles 和 Heroic 进行实时检测。

Windows、macOS、Linux

一个桌面应用，一个账户，一套存档。Proton/Wine 前缀被识别为一等目标。

随时可带走的是你自己的数据

按游戏写入的原样导出每个存档，无打包，无专有封装。免费套餐也包含。

5. 自托管

同一个二进制，你的硬件。

服务器是 AGPL-3.0 下的单个 Rust 二进制文件。无需账户，没有配额，除了你的磁盘没有别的限制。在 Raspberry Pi 上也能流畅运行。

GitHub 上的安装指南 
mkdir hoard && cd hoard
curl -O https://raw.githubusercontent.com/\
rleeon/hoard/main/deploy/docker/docker-compose.yml
docker compose up -d

6. 指南

适合各种场景的指南

所有指南

  • 如何在多台 PC 之间同步游戏存档

    在台式机、笔记本和 Steam Deck 上游玩而不丢进度：在多台 PC 之间自动同步游戏存档并保留版本历史，分步讲解。

  • Steam 云存档的替代方案：同步并备份 Steam 管不到的存档

    Steam Cloud 不支持很多游戏，也不保留历史。在 PC 和 Steam Deck 之间同步并备份任何启动器里的每款游戏，附可回滚的版本历史。

  • 如何备份和同步模拟器存档（RetroArch、Dolphin、PCSX2）

    在 PC 和 Steam Deck 之间备份与同步 RetroArch、Dolphin、PCSX2、DuckStation 等模拟器存档，保留版本历史，并列出各自的存档位置。
