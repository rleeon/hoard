About Hoard

Three lengths, ready to paste. Use them as they are or as a starting point.

One line

Hoard is a free, open-source app that backs up game saves and keeps them in sync across PCs and Steam Deck, with every version kept.

Short

Hoard backs up game saves automatically and syncs them between Windows, macOS, Linux and Steam Deck: stop playing on one machine and the game is waiting on the next. Every change is kept as a version to roll back to. It finds saves for Steam, GOG, Epic, itch.io and emulators on its own. Players can use the free Hoard Cloud, hosted in the EU, or run the same open-source server on their own hardware.

Long

Hoard is a free, open-source tool that backs up and syncs PC game saves. A small background service watches the folders games save into; when a session ends, it stores the change as a new version and syncs it to the player's other machines, on Windows, macOS, Linux and Steam Deck. Saves for Steam, GOG, Epic, itch.io, emulators and Proton or Wine prefixes are detected on their own, and any folder can be added by hand. Versions are deduplicated by content hash, so ten versions of a 2 GB save take about 2 GB, not 20, and every file is checked with SHA-256. There are two ways to run it. Hoard Cloud is the managed option, hosted in the EU, with a free plan. Self-hosting runs the same server on one's own hardware, from a NAS to a Raspberry Pi, with no account with Hoard, no quotas and nothing sent to the project. Hoard is written in Rust, licensed under AGPL-3.0 and built by an independent developer, Raimundo León Oliva.
