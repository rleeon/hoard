About Hoard

Three lengths, ready to paste. Use them as they are or as a starting point.

One line

Hoard is a free, open-source app that backs up game saves and keeps them in sync across devices, with every version kept.

Short

Hoard backs up game saves automatically and syncs them between Windows, macOS, Linux and Steam Deck: stop playing on one machine and the game is waiting on the next. Every change is kept as a version to roll back to. It finds saves for thousands of games on its own, whatever store they came from, plus emulators. Players can use the free Hoard One, hosted in the EU, or run the same open-source server on their own hardware.

Long

Hoard is a free, open-source tool that backs up and syncs PC game saves. A small background service watches the folders games save into; when a session ends, it stores the change as a new version and syncs it to the player's other machines, on Windows, macOS, Linux and Steam Deck. Saves for thousands of games are detected on their own, whatever store they came from, along with emulators and Proton or Wine prefixes, and any folder can be added by hand. Versions are deduplicated by content hash, so ten versions of a 2 GB save take about 2 GB, not 20, and every file is checked with SHA-256. There are two ways to run it. Hoard One is the managed option, hosted in the EU, with a free plan. Self-hosting runs the same server on one's own hardware, from a NAS to a Raspberry Pi, with no account with Hoard, no quotas and nothing sent to the project. Hoard is written in Rust, licensed under AGPL-3.0 and built by an independent developer, Raimundo León Oliva.

Latest release

v1.3.0 · October 25, 2026

Hoard Cloud becomes Hoard One and Pro can be bought as a single year. The Steam Deck gets a Game Mode plugin, arrow-key navigation and detection for games added to Steam as shortcuts. Uploads get faster and lighter, one file can be pulled out of any old version without restoring it, and sync keeps running on Linux machines that nobody has logged in to.

New

  • · A Steam Deck plugin for Game Mode.
  • · A year of Pro, paid once.
  • · Download a version without restoring it.
  • · Move around the app with the arrow keys.
  • · Games added to Steam as shortcuts are found.
  • · Halloween, from 24 October to 3 November.
  • · Hoard-help can attach your server's log.
  • · Notifications for downloads from the cloud.

Changed

  • · Hoard Cloud is now Hoard One.
  • · Faster, lighter uploads.
  • · Panel cards fit the screen.
  • · Hoard One learns which parts of the app get used.
Fixed (9)
  • · "Back up now" did nothing after a run of failures.
  • · The app opened and closed at once on some Linux handhelds.
  • · The AppImage would not open in sandboxes such as firejail.
  • · The app could show nothing in the Steam Deck's Game Mode.
  • · The app sometimes switched to the system language.
  • · Sync stayed off on Linux machines where nobody had logged in.
  • · Changing a setting in History could freeze the window for a minute.
  • · Pro could drop to Free for a moment at each renewal.
  • · "Change plan" could start a second Pro subscription.
